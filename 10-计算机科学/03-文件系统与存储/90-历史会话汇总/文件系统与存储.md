# 文件系统与存储

> 来源：OpenCode 历史会话 | ~5 条

## Btrfs 快照

```bash
# 创建快照
btrfs subvolume snapshot / /snapshots/root-$(date +%Y%m%d)

# 列出快照
btrfs subvolume list /

# 删除快照
btrfs subvolume delete /snapshots/root-20260101

# 回退：恢复快照为新的根子卷
```

快照用途：
- 系统崩溃前备份
- 更新前的安全点
- 增量备份基础

## 单硬盘 Arch 安装

分区方案：
- UEFI：ESP 分区（512MB+）+ 根分区
- `/boot` 可独立分区或在根分区下
- 推荐 btrfs + 子卷布局：

```
/mnt/@              → /
/mnt/@home          → /home
/mnt/@snapshots     → /.snapshots
/mnt/@var_log       → /var/log
```

## grub 目录布局

| 启动模式 | grub 文件位置 | ESP 挂载点 |
|----------|--------------|------------|
| BIOS/Legacy | `/boot/grub/` | 无 |
| UEFI | ESP 分区的 `/EFI/` | `/boot` 或 `/efi` |

BIOS 模式 grub 安装在 MBR，UEFI 模式安装在 ESP。

## 修改文件夹权限

```bash
chmod 755 <dir>           # rwxr-xr-x
chown user:group <dir>    # 更改所有者
chmod -R 755 <dir>        # 递归
```

配合 ACL：
```bash
setfacl -R -m u:user:rwx <dir>
```

## Linux 文件系统大小写

- ext4 / XFS / Btrfs：**大小写敏感**
- NTFS / FAT / exFAT：默认**不敏感**
- 可通过挂载选项调整（如 vfat 的 `shortname`）
