# 磁盘调度算法

## 磁盘结构

- **磁道**（Track）：同心圆
- **扇区**（Sector）：磁道的分段
- **柱面**（Cylinder）：所有盘面相同磁道的集合

## 访问时间

```
磁盘访问时间 = 寻道时间 + 旋转延迟 + 数据传输时间
```

- **寻道时间**：磁头移动到目标磁道（**最主要**，占大部分时间）
- **旋转延迟**：等待目标扇区转到磁头下方
- **数据传输时间**：实际读写数据

## 调度算法

### FCFS

按请求到达顺序服务。公平但寻道时间长。

### SSTF（最短寻道时间优先）

选择离当前磁头最近的请求。
- 平均寻道时间短
- 可能导致**饥饿**

### SCAN（电梯算法）

磁头单向移动，到达端点后反向。
- 无饥饿
- 两端请求等待时间不均匀

### C-SCAN（循环扫描）

磁头单向移动，到达端点后**直接回到起点**重新开始。
- 更公平

### LOOK / C-LOOK

SCAN/C-SCAN 的改进：不必移动到端点，只需到达该方向最后一个请求就反向/返回。

## 比较

| 算法 | 寻道时间 | 饥饿 | 公平性 |
|------|----------|------|--------|
| FCFS | 长 | 无 | 最公平 |
| SSTF | 短 | 有 | 不公平 |
| SCAN | 中等 | 无 | 较公平 |
| C-SCAN | 中等 | 无 | 最均匀 |
| LOOK | 中等 | 无 | 较公平 |
