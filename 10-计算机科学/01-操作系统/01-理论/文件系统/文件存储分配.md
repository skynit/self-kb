# 文件存储分配

## 连续分配

- 文件占用**连续的磁盘块**
- 优点：顺序和随机访问都快
- 缺点：**外部碎片**，文件大小难以扩展

## 链接分配

- 文件的磁盘块通过**指针链接**
- 隐式链接：每块末尾存下一块地址
- 显式链接：集中存放（**FAT 表**）
- 优点：无外部碎片
- 缺点：随机访问慢（需沿链遍历），指针占空间

### FAT（文件分配表）

将所有块的链接信息集中存放在一张表中，缓存在内存中可加速访问。FAT32、exFAT 即此方案。

## 索引分配

- 为每个文件分配一个**索引块**，存放所有数据块的地址
- 优点：支持随机访问，无外部碎片
- 缺点：索引块占空间

### 多级索引

索引块太大时，对索引本身再建索引：
- Unix inode 采用**直接指针 + 一级间接 + 二级间接 + 三级间接**

```
inode:
├── 直接指针 ×12    → 直接指向数据块
├── 一级间接指针 ×1  → 索引块 → 数据块
├── 二级间接指针 ×1  → 索引块 → 索引块 → 数据块
└── 三级间接指针 ×1  → 索引块 → 索引块 → 索引块 → 数据块
```

## 比较

| 方式 | 访问速度 | 碎片 | 扩展性 |
|------|----------|------|--------|
| 连续分配 | 最快 | 外部碎片 | 差 |
| 链接分配 | 慢 | 无 | 好 |
| 索引分配 | 中等 | 无 | 好 |
