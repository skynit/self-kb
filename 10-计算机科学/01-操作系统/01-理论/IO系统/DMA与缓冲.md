# DMA 与缓冲

## DMA（Direct Memory Access）

### 工作原理

DMA 控制器直接在**IO 设备和内存**之间传输数据，不经过 CPU。

### DMA 控制器寄存器

| 寄存器 | 功能 |
|--------|------|
| 命令/状态寄存器 | 控制 DMA 操作 |
| 内存地址寄存器 | 数据目标内存地址 |
| 数据计数寄存器 | 传输字节数 |

### DMA 传输过程

1. CPU 向 DMA 控制器设置参数（地址、字节数、方向）
2. DMA 控制器接管总线，直接传输
3. 传输完成 → DMA 向 CPU 发中断

### DMA vs 通道

- DMA 只能传输连续内存块
- 通道可执行复杂 IO 程序，一次可处理多条 IO 指令

## 缓冲技术

### 为什么需要缓冲？

- CPU 速度 >> IO 设备速度
- 缓冲区匹配速度差异，提高并行度

### 缓冲策略

| 策略 | 说明 | 特点 |
|------|------|------|
| **单缓冲** | 一个缓冲区 | CPU 和 IO 串行 |
| **双缓冲** | 两个缓冲区交替使用 | CPU 和 IO 可并行 |
| **循环缓冲** | 多个缓冲区轮转 | 高并行度 |
| **缓冲池** | 系统公共缓冲区 | 最灵活，OS 常用 |

### 缓冲区计算公式

设 T 为 IO 时间，M 为缓冲区传输时间，C 为 CPU 处理时间：
- 单缓冲：max(C, T) + M
- 双缓冲：max(C, T)
