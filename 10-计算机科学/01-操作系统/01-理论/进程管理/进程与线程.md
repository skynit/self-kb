# 进程与线程

## 进程（Process）

进程是程序的**一次执行实例**，是系统资源分配的基本单位。

### 进程控制块（PCB）

PCB 是进程存在的唯一标识，包含：

- **PID**：进程标识符
- **进程状态**：就绪/运行/阻塞
- **程序计数器**（PC）：下一条指令地址
- **寄存器值**：上下文信息
- **内存指针**：代码段、数据段、堆栈地址
- **I/O 状态**：打开的文件、分配的设备

### 进程状态转换

```
         创建
          ↓
        就绪态 ←—————┐
       ↙    ↖       |
     运行态 → 阻塞态
       ↓       ↓
     终止态   (等待事件完成)
```

| 转换 | 触发条件 |
|------|----------|
| 就绪 → 运行 | 被调度程序选中 |
| 运行 → 就绪 | 时间片用完 / 被抢占 |
| 运行 → 阻塞 | 等待 I/O 或事件 |
| 阻塞 → 就绪 | I/O 完成 / 事件发生 |

## 线程（Thread）

线程是 CPU 调度的基本单位，一个进程可包含多个线程。

### 进程 vs 线程

| 比较维度 | 进程 | 线程 |
|----------|------|------|
| 资源分配 | 基本单位 | 共享所属进程资源 |
| CPU 调度 | 较重 | 基本单位，较轻 |
| 独立性 | 独立地址空间 | 共享地址空间 |
| 切换开销 | 大（需切换页表等） | 小（只需切换寄存器） |
| 通信方式 | IPC（管道、共享内存等） | 直接读写共享变量 |

### 线程的实现方式

| 方式 | 管理者 | 特点 |
|------|--------|------|
| 用户级线程 | 用户态库 | 切换快，但一个线程阻塞整个进程阻塞 |
| 内核级线程 | 内核 | 可真正并行，但切换开销大 |
| 组合方式 | 两者结合 | 多对多映射 |

## 协程（Coroutine）

用户态的轻量级线程，由程序员自行调度，无内核切换开销。适用于 I/O 密集型场景。

## 经典考点

> - 进程是**资源分配**的基本单位，线程是 **CPU 调度**的基本单位
> - 同一进程的线程共享：代码段、全局变量、打开的文件
> - 线程独享：栈、寄存器、程序计数器
