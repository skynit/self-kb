# 分页与分段

## 基本分页

将内存和进程都划分为**等大**的小块：
- 进程的块叫**页**（Page）
- 内存的块叫**页框/页帧**（Frame）
- 页大小通常为 4KB

### 地址转换

```
逻辑地址 = 页号 + 页内偏移
物理地址 = 页框号 × 页大小 + 页内偏移
```

通过**页表**映射：页号 → 页框号

### 快表（TLB）

页表在内存中，每次访问需两次内存访问（查页表 + 取数据）。

TLB（Translation Lookaside Buffer）是高速缓存，存放常用页表项：
- TLB 命中 → 一次内存访问
- TLB 未命中 → 两次内存访问

## 多级页表

页表太大时，对页表本身再分页：
- 二级页表：外层页表 → 内层页表 → 物理地址
- 减少页表占用的连续内存空间

## 基本分段

按程序的**逻辑结构**分段（代码段、数据段、栈段等）：
- 各段长度**不等**
- 段表：段号 → 段基址 + 段长

## 分页 vs 分段

| 比较 | 分页 | 分段 |
|------|------|------|
| 目的 | 提高内存利用率 | 满足用户逻辑需求 |
| 大小 | 固定（硬件决定） | 不等（逻辑决定） |
| 地址空间 | 一维 | 二维（段号 + 段内偏移） |
| 碎片 | 内部碎片 | 外部碎片 |
| 共享与保护 | 不方便 | 方便（按段共享） |

## 段页式

先分段，再在每段内分页。兼具两者优点，但地址转换更复杂（需三次访存）。
