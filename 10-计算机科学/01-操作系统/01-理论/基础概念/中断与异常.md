# 中断与异常

## 概念区分

| 类型                | 来源     | 触发原因       | 示例             |
| ----------------- | ------ | ---------- | -------------- |
| **中断**（Interrupt） | 外部设备   | 异步，与当前指令无关 | I/O 完成、时钟中断    |
| **异常**（Exception） | CPU 内部 | 同步，由当前指令引发 | 除零错误、缺页异常、系统调用 |

## 中断处理过程

1. 关中断（防止新中断打断）
2. 保存断点（PC、PSW 压栈）
3. 识别中断源
4. 保存现场（通用寄存器等）
5. 执行中断服务程序
6. 恢复现场
7. 开中断
8. 返回断点继续执行

## 中断分类

### 硬中断

- **可屏蔽中断**：I/O 中断，可以被关中断屏蔽
- **不可屏蔽中断**（NMI）：严重硬件故障

### 软中断

- 通过指令主动触发（如 `int 0x80`、`syscall`）
- 用于系统调用

## 异常分类

| 类型        | 说明     | 处理方式            |
| --------- | ------ | --------------- |
| 故障（Fault） | 可恢复的错误 | 修复后重新执行该指令（如缺页） |
| 陷阱（Trap）  | 有意触发   | 执行下一条指令（如系统调用）  |
| 终止（Abort） | 不可恢复   | 终止进程            |

## 考点提示

> 中断是操作系统**驱动力**的核心。没有中断，OS 就无法实现并发、调度等基本功能。理解中断机制是理解整个 OS 的基础。
