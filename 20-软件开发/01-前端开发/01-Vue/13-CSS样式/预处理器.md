# 预处理器与 PostCSS

## 速查

### Sass / SCSS

```vue
<style lang="scss" scoped>
$primary: #1677ff;
$spacing: 16px;

.card {
  color: $primary;
  padding: $spacing;

  .title {
    font-size: 20px;
  }

  &__body {
    margin-top: $spacing / 2;
  }
}
</style>
```

```bash
npm install -D sass
```

### Less

```vue
<style lang="less" scoped>
@primary: #1677ff;

.card {
  color: @primary;
  .title { font-size: 20px; }
}
</style>
```

```bash
npm install -D less
```

### PostCSS

```vue
<style scoped>
/* 自动处理的插件语法 */
.card {
  /* autoprefixer 自动添加浏览器前缀 */
  display: flex;
  user-select: none;
}
</style>
```

```bash
npm install -D postcss autoprefixer
```

```js
// postcss.config.js
export default {
  plugins: {
    autoprefixer: {},
    'postcss-nesting': {},   // CSS 嵌套（原生 now, but polyfill for older browsers）
    'postcss-pxtorem': {     // px → rem
      rootValue: 16,
      propList: ['*']
    }
  }
}
```

## 深入：全局变量注入

```js
// vite.config.js — 自动注入 Sass 变量（无需每个文件 @import）
export default defineConfig({
  css: {
    preprocessorOptions: {
      scss: {
        additionalData: `@use "@/styles/variables" as *;`
      }
    }
  }
})
```

```
src/styles/
├── variables.scss     // 变量：颜色、间距、字体
├── mixins.scss        // 常用混入
├── resets.scss        // 重置样式
├── transitions.scss   // 过渡动画
└── index.scss         // 统一导入
```

```scss
// variables.scss
$colors: (
  primary: #1677ff,
  success: #52c41a,
  error: #ff4d4f,
  text: rgba(0, 0, 0, 0.85),
);

$spacing: 4px, 8px, 12px, 16px, 24px, 32px, 48px;
$breakpoints: (
  sm: 576px,
  md: 768px,
  lg: 992px,
  xl: 1200px,
);
```

```scss
// mixins.scss
@mixin flex-center {
  display: flex;
  align-items: center;
  justify-content: center;
}

@mixin respond-to($bp) {
  @media (min-width: map-get($breakpoints, $bp)) {
    @content;
  }
}

// 使用
.container {
  @include flex-center;
  @include respond-to(md) {
    max-width: 960px;
  }
}
```

## 深入：Tailwind CSS 集成

```bash
npm install -D tailwindcss postcss autoprefixer
npx tailwindcss init -p
```

```js
// tailwind.config.js
export default {
  content: ['./index.html', './src/**/*.{vue,ts}'],
  theme: {
    extend: {}
  }
}
```

```css
/* src/styles/main.css */
@tailwind base;
@tailwind components;
@tailwind utilities;
```

```vue
<template>
  <div class="flex items-center gap-4 p-4 bg-white rounded-lg shadow">
    <span class="text-lg font-bold text-gray-800">Hello</span>
  </div>
</template>
```

### Tailwind + Scoped CSS

```vue
<!-- Tailwind 工具类 + scoped 自定义样式混用 -->
<template>
  <button class="px-4 py-2 rounded" :class="$style.custom">Click</button>
</template>

<style module>
.custom {
  background: linear-gradient(to right, #1677ff, #722ed1);
}
</style>
```

## CSS 架构模式

### BEM + Scoped CSS

```vue
<style scoped>
.block { }
.block__element { }
.block--modifier { }
.block__element--modifier { }
</style>
```

### 属性选择器 + Scoped（推荐）

```vue
<style scoped>
/* scoped 自动处理隔离，关注结构语义即可 */
.card { }
.card-title { }
.card-body { }
</style>
```
