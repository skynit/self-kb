## Vite 环境变量

```ts
// 暴露给客户端
import.meta.env.VITE_API_URL
import.meta.env.VITE_APP_TITLE

// 只有 VITE_ 前缀的变量打包进客户端代码
// .env.production 在 build 时自动加载（mode: production）
```

- `build` 默认 mode 为 `production`
- 对应 `.env.production` 文件
- `.env` 中的非 VITE_ 前缀变量只能在 vite.config.ts 服务端使用

## CORS 与图片请求

前端图片请求失败但 URL 直接访问正常 → 排查顺序：
1. CORS 策略：服务端需返回 `Access-Control-Allow-Origin` 头
2. Referrer-Policy：可能阻止跨域引用
3. Vite 代理配置：`vite.config.ts` 中 proxy 是否正确转发
4. 图片服务器防盗链检查
