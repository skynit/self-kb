以下是 Lazygit 的完整快捷键与功能笔记，按面板分类整理，覆盖日常所有 Git 操作场景。

## 图例说明

## 一、全局快捷键（任何面板下通用）

| 快捷键           | 功能             | 说明                                     |
| ------------- | -------------- | -------------------------------------- |
| `P`           | 推送             | 推送当前分支到上游；未配置上游会提示设置                   |
| `p`           | 拉取             | 从远程拉取当前分支的改动                           |
| `R`           | 刷新             | 刷新 Git 状态（status、branch 等），不会执行 fetch  |
| `z`           | 撤销             | 通过 reflog 撤销上一个 Git 命令（只涉及提交，不包含工作树改动） |
| `<c-z>`       | 重做             | 通过 reflog 重做上一个被撤销的命令                  |
| `?`           | 打开菜单/帮助        | 查看当前上下文可用的所有快捷键                        |
| `m`           | 合并/变基选项        | 查看当前合并或变基的中止/继续/跳过选项                   |
| `:`           | 执行 Shell 命令    | 调出提示符执行任意 shell 命令                     |
| `+`           | 下一屏模式          | 在正常/半屏/全屏间切换                           |
| `_`           | 上一屏模式          | 切换回上一屏模式                               |
| `<c-r>`       | 切换仓库           | 切换到最近使用过的仓库                            |
| `@`           | 命令日志菜单         | 查看/隐藏/聚焦命令日志                           |
| `<c-s>`       | 按路径过滤          | 按文件路径过滤提交日志                            |
| `W` 或 `<c-e>` | Diff 菜单        | 比较两个引用、输入要比较的 ref、反转比较方向               |
| `<c-w>`       | 切换空白字符显示       | 在 diff 视图中切换是否显示空白字符差异                 |
| `}` / `{`     | 扩大/缩小 diff 上下文 | 调整 diff 视图显示的行数范围                      |
| `)` / `(`     | 提高/降低重命名相似度阈值  | 调整删除+添加对被识别为重命名的阈值                     |
| `q`           | 退出             | 退出 Lazygit                             |
| `<esc>`       | 取消             | 取消当前操作                                 |

面板导航快捷键：

| 快捷键 | 功能 |
|--------|------|
| `,` / `.` | 上一页 / 下一页 |
| `<` / `>` | 滚动到顶部 / 底部 |
| `/` | 开始搜索 |
| `H` / `L` | 向左 / 向右滚动 |
| `]` / `[` | 下一个 / 上一个标签 |
| `v` | 切换拖动选择 |
| `<s-down>` / `<s-up>` | 向下/向上扩展选择范围 |

## 四、Branches 面板（分支操作）



| 快捷键       | 功能        | 说明                   |
| --------- | --------- | -------------------- |
| `<space>` | 切换分支      | 检出选中的分支              |
| `c`       | 创建新分支     | 从当前 HEAD 创建新分支       |
| `d`       | 删除分支      | 删除选中的分支              |
| `m`       | 合并        | 将选中分支合并到当前分支         |
| `r`       | 变基        | 将当前分支变基到选中分支         |
| `f`       | 快进        | 快进选中分支（如果可能）         |

| `y`       | 复制分支名到剪贴板 |                      |


## 五、Commits 面板（提交历史操作）

### 5.1 查看与导航

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `<c-o>` | 复制提交哈希 | 复制选中提交的 SHA 到剪贴板 |
| `y` | 复制提交属性 | 复制 hash、URL、diff、消息、作者等 |
| `o` | 在浏览器中打开 | 在浏览器中打开提交（需配置远程） |
| `n` | 从提交创建分支 | 从选中的提交创建新分支 |
| `b` | Bisect | 标记提交为 good/bad 开始 git bisect |

### 5.2 交互式变基（Interactive Rebase）

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `i` | 开始交互式变基 | 从合适的基础开始变基 |
| `e` | 编辑提交 | 在变基中编辑该提交 |
| `s` | 压缩（Squash） | 将提交压缩到前一个提交 |
| `f` | 修正（Fixup） | 将提交修正到前一个提交（丢弃消息） |
| `d` | 丢弃（Drop） | 在变基中删除该提交 |
| `r` 或 `R` | 改写（Reword） | 修改提交信息 |
| `<c-k>` / `<c-j>` | 上移/下移 | 在变基 TODO 列表中移动提交位置 |
| `<s-down>` | 选择范围 | 选中多个提交进行批量操作 |

完成变基操作后，按 `m` 调出菜单选择 `continue` 继续。

### 5.3 挑选（Cherry-pick）

| 快捷键 | 功能 |
|--------|------|
| `c` | 复制提交（进入挑选模式） |
| `v` | 粘贴（应用挑选的提交） |
| `<c-r>` | 重置挑选选择 |

## 七、冲突解决（Merge/Rebase 冲突）

当文件状态显示为 `UU` 或 `AA` 时：

| 快捷键 | 功能 |
|--------|------|
| `<enter>` | 进入冲突文件视图 |
| `<space>` | 选择保留哪一方的修改 |
| `e` | 用外部编辑器手动编辑 |
| `<esc>` | 退出冲突视图 |
| `m` → `continue` | 所有冲突解决后继续合并/变基 |
| `m` → `abort` | 中止当前合并/变基 |
| `m` → `skip` | 跳过当前提交 |

## 九、高级功能速查

### 9.1 逐行暂存（Partial Staging）
- 在 Files 面板进入文件 diff 视图
- `<space>`：暂存选中的行
- `v`：开始选择行范围
- `a`：选择整个 hunk

### 9.2 重置选项
- `d`：打开重置菜单
  - 选择 `nuke`：彻底清除工作树所有改动（包括脏的子模块）

### 9.3 自定义补丁
- `<c-p>`：查看自定义补丁选项
- 在 Commits 面板可切换文件是否包含在补丁中

### 9.4 Diff 比较
- `W` 或 `<c-e>`：打开 diff 菜单
  - 与选中的 ref 进行比较
  - 输入要比较的 ref
  - 反转比较方向


## 十、常用工作流速查

| 场景           | 操作流程                                                                        |
| ------------ | --------------------------------------------------------------------------- |
| **日常提交**     | `2` → `<space>` 暂存文件 → `c` 输入信息提交                                           |
| **推送代码**     | `P` 推送                                                                      |
| **拉取代码**     | `p` 拉取                                                                      |
| **推送被拒（变基）** | `f` fetch → `3` 选本地分支 → `r` 变基到 origin/分支 → 解决冲突 → `m` → continue → `P` 推送  |
| **切换分支**     | `3` → 选中分支 → `<space>`                                                      |
| **创建分支**     | `3` → `c` → 输入分支名                                                           |
| **删除分支**     | `3` → 选中分支 → `d`                                                            |
| **合并分支**     | `3` → 选中要合并的分支 → `m`                                                        |
| **交互式变基**    | `4` → `i` → 对提交执行 `s`/`f`/`d`/`e`/`r` 或 `<c-k>`/`<c-j>` 移动 → `m` → continue |
| **贮藏改动**     | `5` → `s`                                                                   |
| **应用贮藏**     | `5` → 选中贮藏 → `a` 或 `p`                                                      |
| **撤销操作**     | 任意面板按 `z`                                                                   |
| **解决冲突**     | 选中冲突文件 → `<enter>` → 处理 → `<esc>` → `<space>` 暂存 → `m` → continue           |
| **查看帮助**     | `?`                                                                         |
