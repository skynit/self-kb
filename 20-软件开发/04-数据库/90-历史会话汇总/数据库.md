# 数据库（SQLite / MySQL）

> 来源：OpenCode 历史会话 | ~5 条

## SQLite 字段操作

```sql
-- 修改字段名（SQLite 3.25+）
ALTER TABLE table_name RENAME COLUMN old_name TO new_name;

-- 更新单行字段值
UPDATE table_name SET col = value WHERE condition;

-- SQLite 不支持直接 DROP COLUMN（旧版本），需重建表
-- 3.35+ 支持 ALTER TABLE ... DROP COLUMN
```

## SQLite 查看方法

```bash
sqlite3 database.db    # 进入交互模式

.tables                 # 列出所有表
.schema table_name      # 查看表结构
.mode column            # 列对齐输出
.headers on             # 显示列头
SELECT * FROM table;    # 查询数据
.quit                   # 退出
```

GUI 工具：DB Browser for SQLite (`sqlitebrowser`)

## SQL 字段更名通用语法

| 数据库 | 语法 |
|--------|------|
| SQLite 3.25+ | `ALTER TABLE t RENAME COLUMN old TO new` |
| MySQL | `ALTER TABLE t CHANGE old new datatype` |
| PostgreSQL | `ALTER TABLE t RENAME COLUMN old TO new` |

## MySQL ERROR 2002

```
ERROR 2002 (HY000): Can't connect to local MySQL server through socket
```

原因：
- MySQL 服务未启动
- socket 路径不正确
- 权限问题

解决：
```bash
systemctl start mysqld     # Arch
systemctl start mysql      # Debian/Ubuntu
mysql -h 127.0.0.1 -P 3306 # 用 TCP 绕过 socket
```

## Linux 启动 MySQL

```bash
# Arch
sudo systemctl start mysqld
sudo systemctl enable mysqld

# 初始化（首次安装）
sudo mysql_install_db --user=mysql --basedir=/usr --datadir=/var/lib/mysql
```
