## 图片转 PDF

```bash
# img2pdf（推荐，无损）
img2pdf image1.png image2.jpg -o output.pdf

# ImageMagick
convert image1.png image2.jpg output.pdf

# 批量
for f in *.png; do convert "$f" "${f%.png}.pdf"; done
pdfunite *.pdf merged.pdf
```

## 浏览器视频声音消失

排查顺序：
1. `pavucontrol`（PulseAudio/PipeWire）检查音频输出设备
2. 浏览器标签页是否被静音
3. 音频设备切换（耳机/扬声器）
4. 浏览器音频设置

## 有线耳机音质差

1. `pavucontrol` → Configuration → 选择正确输出模式：
   - `Analog Stereo Duplex`（模拟立体声双工）
   - 避免选择 `Digital Output` 当用模拟耳机时
2. 检查耳机接口接触
3. 检查驱动/固件（`dmesg | grep snd`）
4. 尝试 `alsamixer` 调整增益

## Vim 复制命令

| 命令 | 含义 |
|------|------|
| `y` | yank（复制）选中内容 |
| `yy` | 复制整行 |
| `yiw` | 复制当前单词 |
| `p` | 在光标后粘贴 |
| `P` | 在光标前粘贴 |
| `v` + 移动 | 可视模式选择后 `y` 复制 |
| `"+y` | 复制到系统剪贴板 |

## Cannot read clipboard 错误

浏览器安全策略或 Wayland 下剪贴板协议不兼容：
- 需要用户交互触发（非 JS 主动读取）
- Wayland：`wl-clipboard` 或 `wl-paste`
- VSCode/Electron 应用需启用 Wayland 原生支持
