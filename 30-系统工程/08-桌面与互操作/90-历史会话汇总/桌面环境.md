# 桌面环境 (Arch + niri / Wayland)

> 来源：OpenCode 历史会话 | ~12 条

## niri 桌面

niri 是 Wayland 下的平铺/滚动式窗口管理器。

### Steam 黑屏

Arch + niri 下 Steam 黑屏解决方案：
- 确保 DRI 和 Vulkan 驱动已安装
- Wayland 兼容层：`gamescope`
- 启动选项：`-vulkan` 或 `-gl`

### 进程窗口不可见

Wayland 窗口管理兼容性问题。部分 XWayland 应用窗口可能不显示。

### niri 下文本编辑器

类似 Kate 的 GUI 编辑器：
- `kate`（KDE，功能完整）
- `gedit`（GNOME）
- `mousepad`（轻量）
- 终端编辑器：vim / neovim / helix

### 桌宠

Wayland 环境的桌面宠物程序有限：
- `xeyes`（经典，XWayland 可用）
- Wayland 兼容 overlay 工具
- 某些 conky 配置也可做装饰

## 合盖屏幕仍亮

在 `/etc/systemd/logind.conf` 中设置：
```ini
HandleLidSwitch=suspend
HandleLidSwitchExternalPower=suspend
```

## 触摸板灵敏度

通过 libinput 配置：
```bash
# 查看设备
libinput list-devices

# 调节灵敏度
# /etc/libinput/local-overrides.quirks
```

或通过桌面环境设置界面调节 `libinput Accel Speed`。

## kitty 终端

- 透明度：`background_opacity 0.85`（kitty.conf）
- 暗色模式：kitty 跟随系统或手动设置主题
- 替代 Shell：zsh / bash / fish 任意切换（`chsh`）

## 系统更新后应用崩溃

共享库版本不兼容。解决：
- 重建 AUR 包：`yay -S <aur-pkg> --rebuild`
- 等待上游适配新版依赖
- 使用 Flatpak 版本避免依赖冲突

## 终端暗色模式

- kitty：配置文件 `background #1d1f21`
- 其他终端：各自偏好设置
- 全局 GTK/Qt 暗色主题

## spawn-sh-at-startup dbus

桌面启动时通过 D-Bus 激活服务运行 shell 命令：
```bash
# 示例：在 ~/.config/autostart/ 创建 .desktop 文件
# Exec=spawn-sh-at-startup your-command
```

## dms 窗口透明

dms（display manager service，如 lightdm/sddm）窗口透明：
- 合成器设置不正确
- 主题配置导致
- lightdm 使用 `gtk-greeter` 主题设置

## 任务管理器消失

桌面面板进程崩溃，重启：
- XFCE：`xfce4-panel -r`
- KDE：`plasmashell --replace`
- GNOME：Alt+F2 → `r` → Enter
