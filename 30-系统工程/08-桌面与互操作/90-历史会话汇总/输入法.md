# 输入法

> 来源：OpenCode 历史会话 | ~2 条

## Rime 配置

配置文件位置（取决于输入法框架）：

**fcitx5：**
```
~/.config/fcitx5/rime/
~/.local/share/fcitx5/rime/
```

**ibus：**
```
~/.config/ibus/rime/
~/.local/share/ibus/rime/
```

关键文件：
- `default.custom.yaml`：全局设置
- `*.schema.yaml`：输入方案定义
- `*.dict.yaml`：词库
- `weasel.custom.yaml` / `squirrel.custom.yaml`：前端样式

重新部署：右键托盘图标 → 重新部署，或删除 `rime` 目录后重启。

## 触摸屏干扰输入位置

触摸屏误触干扰光标位置（常见于华为 MateBook Linux）：

Rime 端调整：
- 候选框位置设置（如 `style/horizontal: true`）
- 调整候选框距离光标偏移量

系统端：
- libinput 禁用触摸屏（临时）：
  ```bash
  xinput disable <touchscreen-id>
  ```
- Wayland 下可能需要 compositor 级别配置
