# 网络与无线技术

> 来源：OpenCode 历史会话 | ~12 条

## iwlwifi 驱动

`iwlwifi/pcie/drv.c` 是 Intel WiFi PCIe 驱动入口文件，负责：
- 设备注册与识别
- 固件加载
- PCIe 特定初始化

参数目录 `/sys/module/iwlwifi/parameters/` 包含：`disable_11be`、`disable_11ax`、`power_save`、`bt_coex_active` 等。

`disable_11be=N`：**WiFi 7 (802.11be) 已启用**（N 表示不禁止）。

## Linux 无线命令

```bash
iw phy                    # 列出所有无线物理设备详情（频段/信道/能力）
iw dev                    # 列出所有无线网络接口（wlan0 等）
iw dev wlan0 scan         # 扫描可用 AP
lsmod | grep iwlwifi     # 检查驱动加载状态
lspci -nnk | grep -i net  # 查看网络设备
```

`iw phy` 和 `iw dev` 都为空 → 内核未识别无线网卡，驱动未加载或固件缺失。

## WiFi 与 IEEE 802.11

- WiFi 是品牌名，背后是 IEEE 802.11 标准
- IEEE 802.11 定义 OSI 模型最下两层：**PHY（物理层）** 和 **MAC（介质访问控制层）**
- IEEE = Institute of Electrical and Electronics Engineers（电气电子工程师学会）

### WiFi 版本演进

| 版本 | 标准 | 频段 | 最大速率 |
|------|------|------|----------|
| WiFi 4 | 802.11n | 2.4/5 GHz | 600 Mbps |
| WiFi 5 | 802.11ac | 5 GHz | 6.9 Gbps |
| WiFi 6 | 802.11ax | 2.4/5/6 GHz | 9.6 Gbps |
| WiFi 7 | 802.11be | 2.4/5/6 GHz | 46 Gbps |

## Ethernet 帧格式

MAC 层帧结构：

```
| 目标MAC(6) | 源MAC(6) | 类型/长度(2) | 数据(46-1500) | FCS(4) |
```

## MAC 层 vs PHY 层

| 层 | 职责 |
|-----|------|
| MAC | 信道访问控制、帧封装/解封装、地址寻址、CSMA/CA |
| PHY | 调制解调、信号编解码、频率控制、功率管理 |

## SSE 协议

Server-Sent Events：
- 基于 HTTP 协议
- `Content-Type: text/event-stream`
- 长连接单向推送（服务器 → 客户端）
- 可运行于 HTTPS（TLS）之上
- 协议本身是 HTTP 层，TLS 在传输层

## ToDesk 网络连接

远程桌面工具，连接失败原因：
- NAT 穿透失败
- 防火墙拦截 UDP/TCP 端口
- 网络代理干扰

## 私有 IP 地址

`192.168.1.10` / `192.168.100.41`：私有 C 类地址，常用于路由器/内网设备。范围 `192.168.0.0 - 192.168.255.255`。
