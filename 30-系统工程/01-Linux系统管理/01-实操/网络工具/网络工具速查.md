# 网络工具速查

## 网络配置

### ip — 网络配置（替代 ifconfig）

```bash
ip addr                         # 查看所有网络接口和 IP
ip addr show eth0               # 查看指定接口
ip link                         # 查看链路层状态
ip link set eth0 up             # 启用接口
ip link set eth0 down           # 禁用接口
ip route                        # 查看路由表
ip route add 10.0.0.0/8 via 192.168.1.1  # 添加路由
ip neigh                        # 查看 ARP 表（邻居表）
```

### ss — 套接字统计（替代 netstat）

```bash
ss -t                           # TCP 连接
ss -u                           # UDP 连接
ss -tlnp                        # 监听中的 TCP 端口（带进程名）
ss -s                           # 连接统计摘要
ss -t state established         # 已建立的连接
ss -t 'dport = :80'             # 目标端口 80 的连接
```

| 参数 | 含义 |
|------|------|
| `-t` | TCP |
| `-u` | UDP |
| `-l` | 监听状态 |
| `-n` | 数字显示（不解析域名） |
| `-p` | 显示进程信息 |
| `-a` | 所有状态 |

### ping — 网络连通测试

```bash
ping google.com                 # 持续 ping
ping -c 4 google.com            # 只 ping 4 次
ping -i 0.2 google.com          # 间隔 0.2 秒
```

### traceroute — 路由追踪

```bash
traceroute google.com           # 追踪到目标的路由路径
```

### nslookup / dig — DNS 查询

```bash
nslookup google.com             # DNS 查询
dig google.com                  # 更详细的 DNS 查询
dig +short google.com           # 只返回 IP
dig MX google.com               # 查询邮件记录
```

## 远程连接

### ssh — 安全远程登录

```bash
ssh user@host                   # 连接远程主机
ssh -p 2222 user@host           # 指定端口
ssh -i ~/.ssh/key user@host     # 使用密钥文件
ssh user@host "command"         # 执行远程命令
```

### scp — 安全文件传输

```bash
scp file user@host:/path/       # 上传文件
scp user@host:/path/file .      # 下载文件
scp -r dir user@host:/path/     # 递归上传目录
scp -P 2222 file user@host:/path/  # 指定端口
```

### rsync — 增量同步

```bash
rsync -avz src/ user@host:/dest/    # 同步目录（压缩传输）
rsync -avz --delete src/ dest/      # 同步并删除目标多余文件
rsync -avz --exclude="*.log" src/ dest/  # 排除文件
rsync -avz -e "ssh -p 2222" src/ user@host:/dest/  # 指定 SSH 端口
```

| 参数 | 含义 |
|------|------|
| `-a` | 归档模式（保留权限、时间等） |
| `-v` | 显示详细信息 |
| `-z` | 压缩传输 |
| `--delete` | 删除目标中源没有的文件 |
| `--dry-run` | 模拟运行（不实际传输） |

## HTTP 工具

### curl — HTTP 请求

```bash
curl URL                            # GET 请求
curl -o file.zip URL                # 下载文件
curl -O URL                         # 下载文件（用原文件名）
curl -L URL                         # 跟随重定向
curl -I URL                         # 只获取响应头
curl -X POST -d "key=value" URL     # POST 请求
curl -X POST -H "Content-Type: application/json" -d '{"key":"value"}' URL  # JSON POST
curl -v URL                         # 详细输出（调试）
curl -s URL                         # 静默模式（不显示进度）
curl -s URL | jq .                  # 管道到 jq 解析 JSON
```

### wget — 下载工具

```bash
wget URL                            # 下载文件
wget -O filename URL                # 指定保存文件名
wget -c URL                         # 断点续传
wget -r URL                         # 递归下载
wget -q URL                         # 静默模式
```

### curl vs wget

| | curl | wget |
|--|------|------|
| 下载文件 | ✅ | ✅（更适合批量下载） |
| HTTP 请求 | ✅ 功能丰富 | 基础 |
| 断点续传 | `-C -` | `-c` |
| 递归下载 | ❌ | `-r` |
| 输出到 stdout | 默认 | 需要 `-O-` |

## 防火墙

### iptables（传统）

```bash
iptables -L                         # 列出规则
iptables -A INPUT -p tcp --dport 80 -j ACCEPT  # 允许 80 端口
iptables -A INPUT -s 192.168.1.0/24 -j ACCEPT  # 允许某网段
iptables -D INPUT 3                 # 删除第3条规则
```

### ufw（Ubuntu 简化防火墙）

```bash
ufw status                          # 查看状态
ufw enable                          # 启用防火墙
ufw allow 22/tcp                    # 允许 SSH
ufw allow 80,443/tcp                # 允许 HTTP/HTTPS
ufw deny from 1.2.3.4               # 拒绝某 IP
ufw delete allow 80/tcp             # 删除规则
```

### firewalld（CentOS/RHEL）

```bash
firewall-cmd --state                # 查看状态
firewall-cmd --add-service=http --permanent  # 允许 HTTP
firewall-cmd --reload               # 重新加载
```

## 网络调试

```bash
# 查看端口占用
ss -tlnp | grep :80
lsof -i :80

# 查看网络接口流量
iftop                               # 需要安装
nload                               # 需要安装

# 抓包
tcpdump -i eth0                     # 抓取 eth0 的所有包
tcpdump -i any port 80              # 抓取 80 端口的包
tcpdump -w capture.pcap             # 保存到文件
```
