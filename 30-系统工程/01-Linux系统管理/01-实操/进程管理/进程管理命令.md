# 进程管理命令

## 查看进程

### ps — 进程快照

```bash
ps aux                          # 所有进程（BSD 风格，最常用）
ps -ef                          # 所有进程（System V 风格）
ps aux | grep nginx             # 查找特定进程
ps -u username                  # 某用户的进程
ps -p 1234                      # 指定 PID
ps -eo pid,ppid,user,%cpu,%mem,cmd --sort=-%cpu | head -20  # 按 CPU 排序
```

ps aux 输出字段：

| 字段 | 含义 |
|------|------|
| USER | 进程所有者 |
| PID | 进程 ID |
| %CPU | CPU 使用率 |
| %MEM | 内存使用率 |
| VSZ | 虚拟内存大小 |
| RSS | 物理内存大小 |
| STAT | 进程状态（S=睡眠 R=运行 Z=僵尸 D=不可中断） |
| COMMAND | 启动命令 |

### top — 实时进程监控

```bash
top                             # 实时查看进程
```

top 交互命令：

| 按键 | 功能 |
|------|------|
| `q` | 退出 |
| `k` | 杀死进程（输入 PID） |
| `M` | 按内存排序 |
| `P` | 按 CPU 排序 |
| `1` | 显示每个 CPU 核心 |
| `f` | 选择显示的字段 |
| `H` | 显示线程 |

### htop — 增强版 top

```bash
htop                            # 需要安装：sudo apt install htop
```

比 top 更友好的界面，支持鼠标操作、树形视图、搜索。

## 信号与进程控制

### kill — 发送信号

```bash
kill PID                        # 发送 SIGTERM（15，默认，优雅终止）
kill -9 PID                     # 发送 SIGKILL（强制杀死）
kill -HUP PID                   # 发送 SIGHUP（重新加载配置）
kill -STOP PID                  # 暂停进程
kill -CONT PID                  # 恢复进程
```

常用信号：

| 信号 | 编号 | 含义 |
|------|------|------|
| SIGTERM | 15 | 优雅终止（默认） |
| SIGKILL | 9 | 强制杀死（不可捕获） |
| SIGHUP | 1 | 挂起/重新加载配置 |
| SIGSTOP | 19 | 暂停 |
| SIGCONT | 18 | 恢复 |

### killall / pkill — 按名称杀进程

```bash
killall nginx                   # 杀死所有 nginx 进程
pkill -f "python server.py"    # 按命令行模式杀进程
```

### 后台进程

```bash
command &                       # 后台运行
jobs                            # 查看后台任务
fg %1                           # 将任务 1 调回前台
bg %1                           # 让任务 1 在后台继续运行
```

### nohup — 断开终端不终止

```bash
nohup command &                 # 终端断开后进程继续运行
nohup python server.py > log.txt 2>&1 &
```

## systemd — 服务管理

### 基本操作

```bash
systemctl start nginx           # 启动服务
systemctl stop nginx            # 停止服务
systemctl restart nginx         # 重启服务
systemctl reload nginx          # 重新加载配置（不中断服务）
systemctl status nginx          # 查看服务状态
```

### 开机自启

```bash
systemctl enable nginx          # 设为开机自启
systemctl disable nginx         # 取消开机自启
systemctl is-enabled nginx      # 检查是否开机自启
```

### 查看服务

```bash
systemctl list-units --type=service             # 所有已加载的服务
systemctl list-units --type=service --state=running  # 运行中的服务
systemctl list-unit-files --type=service        # 所有服务（含未启动的）
```

### 日志（journalctl）

```bash
journalctl -u nginx             # 查看 nginx 日志
journalctl -u nginx -f          # 实时跟踪
journalctl -u nginx --since "1 hour ago"  # 最近1小时
journalctl -u nginx -n 50       # 最近50条
journalctl -p err               # 只看错误级别
```

## 资源监控

### uptime — 系统负载

```bash
uptime                          # 显示运行时间和负载均值
# 输出：load average: 0.50, 0.75, 1.00
# 分别是 1分钟、5分钟、15分钟的平均负载
# 值 < CPU核心数 = 正常
```

### free — 内存使用

```bash
free -h                         # 人类可读的内存使用
free -m                         # 以 MB 为单位
free -s 5                       # 每5秒刷新
```

输出字段：

| 字段 | 含义 |
|------|------|
| total | 总内存 |
| used | 已使用 |
| free | 完全空闲 |
| shared | 共享内存 |
| buff/cache | 缓冲/缓存 |
| available | 可用内存（含可回收缓存） |

> 看内存压力应该看 `available`，不是 `free`。

### vmstat — 虚拟内存统计

```bash
vmstat 2                        # 每2秒刷新
vmstat 2 10                     # 每2秒刷新，共10次
```

### iostat — IO 统计

```bash
iostat -xz 2                    # 扩展磁盘IO统计，每2秒
```

## proc 文件系统

```bash
cat /proc/cpuinfo               # CPU 信息
cat /proc/meminfo               # 内存信息
cat /proc/loadavg               # 负载均值
cat /proc/uptime                # 运行时间
cat /proc/PID/status            # 进程详细状态
cat /proc/PID/cmdline           # 进程启动命令
ls /proc/PID/fd                 # 进程打开的文件描述符
```
