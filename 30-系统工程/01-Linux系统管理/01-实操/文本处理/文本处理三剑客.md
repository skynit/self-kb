# 文本处理三剑客 — grep/sed/awk

## grep — 文本搜索

按模式搜索文本行。

```bash
grep "pattern" file                 # 搜索包含 pattern 的行
grep -i "pattern" file              # 忽略大小写
grep -n "pattern" file              # 显示行号
grep -r "pattern" /path/            # 递归搜索目录
grep -v "pattern" file              # 反选（不包含的行）
grep -c "pattern" file              # 统计匹配行数
grep -l "pattern" *.txt             # 只显示匹配的文件名
grep -w "word" file                 # 全词匹配
grep -A 3 "pattern" file            # 匹配行后3行（After）
grep -B 3 "pattern" file            # 匹配行前3行（Before）
grep -C 3 "pattern" file            # 匹配行前后各3行（Context）
grep -E "pattern1|pattern2" file    # 正则表达式（扩展）
grep -P "\d+" file                  # Perl 正则
```

### 常用正则

```bash
grep "^start" file           # 以 start 开头的行
grep "end$" file             # 以 end 结尾的行
grep "^$" file               # 空行
grep -E "error|warning" log  # 匹配 error 或 warning
grep -E "[0-9]{3}" file      # 匹配连续3个数字
```

## sed — 流编辑器

逐行处理文本，用于替换、删除、插入。

### 替换

```bash
sed 's/old/new/' file               # 每行第一个匹配替换
sed 's/old/new/g' file              # 全局替换（每行所有匹配）
sed 's/old/new/gi' file             # 全局替换 + 忽略大小写
sed -i 's/old/new/g' file           # 原地修改文件（⚠️ 直接改文件）
sed -i.bak 's/old/new/g' file       # 原地修改并备份为 file.bak
```

### 删除

```bash
sed '3d' file                       # 删除第3行
sed '2,5d' file                     # 删除第2-5行
sed '/pattern/d' file               # 删除匹配的行
sed '/^$/d' file                    # 删除空行
```

### 插入/追加

```bash
sed '2i\new line' file              # 在第2行前插入
sed '2a\new line' file              # 在第2行后追加
sed '$a\last line' file             # 在文件末尾追加
```

### 提取

```bash
sed -n '5p' file                    # 只打印第5行
sed -n '2,5p' file                  # 只打印第2-5行
sed -n '/pattern/p' file            # 只打印匹配的行
```

### 多命令

```bash
sed -e 's/foo/bar/g' -e 's/baz/qux/g' file   # 执行多个替换
sed 's/foo/bar/g; s/baz/qux/g' file           # 分号分隔
```

## awk — 列处理

按列/字段处理结构化文本，功能最强大。

### 基本语法

```bash
awk '{print $1}' file               # 打印第1列
awk '{print $1, $3}' file           # 打印第1和第3列
awk '{print NR, $0}' file           # 打印行号和整行
awk '{print NF}' file               # 打印每行的字段数
awk -F: '{print $1}' /etc/passwd    # 指定分隔符为冒号
```

### 条件过滤

```bash
awk '$3 > 100' file                 # 第3列大于100的行
awk '$1 == "error"' file            # 第1列等于 error 的行
awk '/pattern/' file                # 匹配 pattern 的行
awk 'NR >= 2 && NR <= 5' file       # 第2到5行
```

### 内置变量

| 变量 | 含义 |
|------|------|
| `$0` | 整行 |
| `$1, $2, ...` | 第 N 个字段 |
| `NR` | 当前行号 |
| `NF` | 当前行的字段数 |
| `FS` | 输入字段分隔符 |
| `OFS` | 输出字段分隔符 |
| `FILENAME` | 当前文件名 |

### 计算与统计

```bash
awk '{sum += $3} END {print sum}' file            # 第3列求和
awk '{sum += $3; count++} END {print sum/count}' file  # 平均值
awk '{print length($0)}' file                      # 每行长度
```

### BEGIN / END

```bash
awk 'BEGIN {print "Start"} {print $1} END {print "Done"}' file
```

- `BEGIN`：处理第一行之前执行
- `END`：处理最后一行之后执行

### 实用组合

```bash
# 统计日志中各 HTTP 状态码出现次数
awk '{print $9}' access.log | sort | uniq -c | sort -rn

# 统计每个用户的进程数
ps aux | awk 'NR>1 {print $1}' | sort | uniq -c | sort -rn

# 打印 /etc/passwd 中的用户名和 shell
awk -F: '{print $1, $7}' /etc/passwd
```

## 其他文本工具

### sort — 排序

```bash
sort file                           # 按字母排序
sort -n file                        # 按数字排序
sort -r file                        # 逆序
sort -k2 file                       # 按第2列排序
sort -k2 -n file                    # 按第2列数字排序
sort -u file                        # 排序并去重
sort -t: -k3 -n /etc/passwd         # 指定分隔符，按第3列数字排序
```

### uniq — 去重（需先排序）

```bash
sort file | uniq                    # 去重
sort file | uniq -c                 # 去重并统计次数
sort file | uniq -d                 # 只显示重复的行
sort file | uniq -u                 # 只显示唯一的行
```

### cut — 按列截取

```bash
cut -d: -f1 /etc/passwd             # 按冒号分隔，取第1列
cut -d',' -f1,3 file.csv            # 取第1和第3列
cut -c1-10 file                     # 取每行前10个字符
```

### tr — 字符转换

```bash
echo "HELLO" | tr 'A-Z' 'a-z'      # 大写转小写
echo "hello" | tr -d 'l'            # 删除指定字符
echo "aabb" | tr -s 'a'             # 压缩连续重复字符
cat file | tr '\n' ' '              # 换行替换为空格
```

### tee — 同时输出到屏幕和文件

```bash
command | tee file                   # 输出到屏幕并写入文件
command | tee -a file                # 追加模式
```

## 三剑客对比

| 工具 | 擅长 | 典型场景 |
|------|------|----------|
| `grep` | 搜索匹配行 | 查日志、过滤输出 |
| `sed` | 行级替换/删除 | 批量修改配置文件 |
| `awk` | 列级处理/计算 | 解析 CSV、统计日志 |

```
简单搜索 → grep
批量替换 → sed
复杂处理 → awk
```
