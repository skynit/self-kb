# Linux 基础命令速查

## 文件与目录操作

### ls — 列出目录内容

```bash
ls                          # 列出当前目录
ls -l                       # 长格式（权限、大小、时间）
ls -la                      # 含隐藏文件（.开头）
ls -lh                      # 人类可读的文件大小（KB/MB）
ls -lt                      # 按修改时间排序（最新在前）
ls -ltr                     # 按修改时间逆序（最旧在前）
ls -lS                      # 按大小排序（最大在前）
ls -R                       # 递归列出子目录
ls -d */                    # 只列出目录
```

### cd — 切换目录

```bash
cd /path/to/dir             # 绝对路径
cd relative/path            # 相对路径
cd ..                       # 上一级
cd ~                        # 家目录
cd -                        # 上一次所在的目录
cd                          # 等同 cd ~
```

### pwd — 显示当前目录

```bash
pwd                         # 打印当前工作目录
```

### mkdir — 创建目录

```bash
mkdir dirname               # 创建单个目录
mkdir -p a/b/c              # 递归创建多级目录
mkdir dir1 dir2 dir3        # 同时创建多个
```

### cp — 复制

```bash
cp file1 file2              # 复制文件
cp file1 /dest/             # 复制到目标目录
cp -r dir1 dir2             # 递归复制目录
cp -i file1 file2           # 覆盖前确认
cp -v file1 file2           # 显示复制过程
```

### mv — 移动/重命名

```bash
mv file1 file2              # 重命名
mv file1 /dest/             # 移动到目标目录
mv -i file1 file2           # 覆盖前确认
```

### rm — 删除

```bash
rm file                     # 删除文件
rm -r dir                   # 递归删除目录
rm -f file                  # 强制删除（不确认）
rm -rf dir                  # 强制递归删除（⚠️ 危险！）
rm -i file                  # 删除前确认
```

> ⚠️ `rm -rf /` 会删除整个系统，绝对不要执行！

### touch — 创建空文件/更新时间戳

```bash
touch file.txt              # 创建空文件（或更新已有文件的修改时间）
touch -t 202601011200 file  # 设置特定时间戳
```

### find — 查找文件

```bash
find /path -name "*.txt"          # 按名称查找
find /path -iname "*.TXT"         # 忽略大小写
find /path -type f                # 只找文件
find /path -type d                # 只找目录
find /path -size +100M            # 大于 100MB
find /path -mtime -7              # 7天内修改过的
find /path -user username         # 属于某用户的
find /path -name "*.log" -delete  # 找到并删除
find /path -name "*.txt" -exec grep "pattern" {} +  # 找到并执行命令
```

### tree — 目录树

```bash
tree                        # 显示目录树
tree -L 2                   # 只显示2层
tree -d                     # 只显示目录
```

## 文件查看

### cat — 查看文件内容

```bash
cat file                    # 显示全部内容
cat -n file                 # 带行号
cat file1 file2             # 合并显示多个文件
```

### less / more — 分页查看

```bash
less file                   # 分页查看（推荐，支持搜索）
# 按 q 退出，/pattern 搜索，n 下一个，N 上一个
```

### head / tail — 查看首尾

```bash
head -n 20 file             # 前20行
tail -n 20 file             # 后20行
tail -f file                # 实时跟踪文件新增内容（日志监控）
tail -f /var/log/syslog     # 实时查看系统日志
```

### wc — 统计

```bash
wc file                     # 行数 词数 字节数
wc -l file                  # 只统计行数
wc -w file                  # 只统计词数
wc -c file                  # 只统计字节数
```

## 文件权限与所有权

### chmod — 修改权限

```bash
chmod 755 file              # rwxr-xr-x
chmod 644 file              # rw-r--r--
chmod +x script.sh          # 添加执行权限
chmod -w file               # 去掉写权限
chmod u+x file              # 只给所有者加执行权限
chmod go-w file             # 去掉组和其他人的写权限
```

权限数字对照：`r=4, w=2, x=1`，三组（所有者/组/其他）相加。

### chown — 修改所有权

```bash
chown user file             # 修改所有者
chown user:group file       # 同时修改所有者和组
chown -R user:group dir     # 递归修改目录
```

## 链接

### ln — 创建链接

```bash
ln file hardlink            # 硬链接（同一 inode）
ln -s target symlink        # 软链接/符号链接（类似快捷方式）
ls -l                       # 软链接显示为 -> target
```

| 类型 | 硬链接 | 软链接 |
|------|--------|--------|
| 跨文件系统 | ❌ 不可以 | ✅ 可以 |
| 链接目录 | ❌ 不可以 | ✅ 可以 |
| 原文件删除 | 仍可访问 | 链接失效（悬空） |
| inode | 相同 | 不同 |

## 磁盘与存储

### df — 磁盘空间

```bash
df -h                       # 人类可读的磁盘使用情况
df -h /home                 # 指定挂载点
df -T                       # 显示文件系统类型
```

### du — 目录大小

```bash
du -sh dir                  # 目录总大小
du -sh *                    # 当前目录下各项大小
du -sh * | sort -rh         # 按大小排序
du -h --max-depth=1         # 只统计一层
```

### mount / umount — 挂载

```bash
mount                       # 显示所有挂载
mount /dev/sdb1 /mnt/usb    # 挂载设备
umount /mnt/usb             # 卸载
```

## 压缩与解压

```bash
# tar
tar -czf archive.tar.gz dir/        # 创建 gzip 压缩包
tar -cjf archive.tar.bz2 dir/       # 创建 bzip2 压缩包
tar -xzf archive.tar.gz             # 解压 gzip
tar -xzf archive.tar.gz -C /dest/   # 解压到指定目录
tar -tf archive.tar.gz              # 列出压缩包内容

# zip
zip -r archive.zip dir/             # 创建 zip
unzip archive.zip                    # 解压 zip
unzip archive.zip -d /dest/         # 解压到指定目录

# gzip / gunzip
gzip file                            # 压缩（替换原文件）
gunzip file.gz                       # 解压
```

## 命令组合技巧

```bash
# 管道：前一个命令的输出作为后一个命令的输入
ls -la | grep ".txt"               # 过滤 .txt 文件
ps aux | grep nginx                # 查找 nginx 进程
cat file | sort | uniq             # 排序去重
cat file | wc -l                   # 统计行数

# 重定向
echo "hello" > file                # 覆盖写入
echo "world" >> file               # 追加写入
command 2>&1                       # 合并标准错误和标准输出
command > /dev/null 2>&1           # 丢弃所有输出

# 命令替换
echo "Today is $(date +%Y-%m-%d)"  # 嵌入命令结果
```
