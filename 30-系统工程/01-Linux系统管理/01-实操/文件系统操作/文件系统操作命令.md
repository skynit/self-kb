# 文件系统操作命令

## 磁盘分区

### fdisk — MBR 分区工具

```bash
sudo fdisk -l                     # 列出所有磁盘和分区
sudo fdisk /dev/sdb               # 交互式分区（MBR）
```

fdisk 交互命令：

| 命令 | 功能 |
|------|------|
| `p` | 打印分区表 |
| `n` | 新建分区 |
| `d` | 删除分区 |
| `t` | 更改分区类型 |
| `w` | 写入并退出 |
| `q` | 不保存退出 |

### parted — GPT 分区工具

```bash
sudo parted /dev/sdb              # 交互式分区（支持 GPT）
sudo parted /dev/sdb print        # 显示分区信息
sudo parted /dev/sdb mklabel gpt  # 创建 GPT 分区表
sudo parted /dev/sdb mkpart primary ext4 0% 100%  # 创建分区
```

### fdisk vs parted

| | fdisk | parted |
|--|-------|--------|
| 分区表 | MBR（也支持 GPT） | MBR + GPT |
| 大于 2TB | ❌ MBR 不支持 | ✅ GPT 支持 |
| 交互式 | ✅ | ✅ |
| 脚本化 | 需要 echo 管道 | `parted` 命令行参数 |

## 文件系统创建与挂载

### mkfs — 创建文件系统

```bash
sudo mkfs.ext4 /dev/sdb1         # 创建 ext4
sudo mkfs.xfs /dev/sdb1          # 创建 XFS
sudo mkfs.vfat /dev/sdb1         # 创建 FAT32
sudo mkfs.btrfs /dev/sdb1        # 创建 Btrfs
```

### mount / umount — 挂载/卸载

```bash
mount                           # 显示所有挂载
mount /dev/sdb1 /mnt/data       # 挂载到 /mnt/data
mount -t ext4 /dev/sdb1 /mnt    # 指定文件系统类型
mount -o ro /dev/sdb1 /mnt      # 只读挂载
mount -o remount,rw /mnt        # 重新挂载为读写
umount /mnt/data                # 卸载
umount -l /mnt/data             # 延迟卸载（忙碌时）
```

### /etc/fstab — 开机自动挂载

```
# 设备路径                          挂载点      文件系统  选项        dump fsck
UUID=xxxx-xxxx                     /           ext4     defaults    0 1
UUID=yyyy-yyyy                     /home       ext4     defaults    0 2
UUID=zzzz-zzzz                     /boot/efi   vfat     umask=0077  0 2
/dev/mapper/swap                   swap        swap     defaults    0 0
```

```bash
# 获取 UUID
blkid /dev/sdb1

# 测试 fstab（不重启）
sudo mount -a

# 查看当前挂载
findmnt
```

> ⚠️ fstab 配置错误会导致系统无法启动！修改前务必备份。

## 空间管理

### df — 磁盘使用

```bash
df -h                           # 人类可读
df -hT                          # 含文件系统类型
df -i                           # inode 使用情况（inode 耗尽也会无法写入）
df -h /home                     # 指定挂载点
```

### du — 目录大小

```bash
du -sh /var/log                 # 目录总大小
du -sh *                        # 当前目录各项大小
du -sh * | sort -rh | head -10  # 按大小排序前10
du -h --max-depth=1 /           # 根目录下一级
du -sh --exclude='*.log' .      # 排除文件
```

### ncdu — 交互式磁盘使用分析

```bash
ncdu /                          # 需要安装：sudo apt install ncdu
# 交互式浏览，按 d 删除文件/目录
```

## 文件查找与定位

### find — 详细查找

```bash
find / -name "*.conf" 2>/dev/null           # 全局查找 .conf 文件
find /var -name "*.log" -mtime +30          # /var 下30天前的日志
find /tmp -type f -size +100M               # /tmp 下大于100MB的文件
find /home -type f -perm 777                # 权限为 777 的文件
find . -name "*.tmp" -exec rm {} +          # 找到并删除
find . -type f -newer reference_file        # 比参考文件更新的文件
```

### locate — 快速查找（基于数据库）

```bash
locate filename                 # 快速查找（需要先 updatedb）
sudo updatedb                   # 更新数据库
```

### which / whereis — 查找命令

```bash
which python3                   # 查找命令路径
whereis nginx                   # 查找命令、源码、手册页
```

## 文件系统信息

### stat — 文件详细信息

```bash
stat file                       # 显示 inode、大小、时间戳等
stat -f /                       # 显示文件系统信息
```

### file — 文件类型

```bash
file image.png                  # 识别文件类型
file *                          # 识别当前目录所有文件类型
```

### lsblk — 块设备列表

```bash
lsblk                           # 列出所有块设备
lsblk -f                        # 含文件系统和 UUID
lsblk -o NAME,SIZE,TYPE,MOUNTPOINT  # 指定输出字段
```

### blkid — 块设备 ID

```bash
blkid                           # 列出所有块设备的 UUID 和类型
blkid /dev/sdb1                 # 指定设备
```

## 交换空间

```bash
# 创建 swap 文件
sudo fallocate -l 2G /swapfile
sudo chmod 600 /swapfile
sudo mkswap /swapfile
sudo swapon /swapfile

# 永久生效：添加到 /etc/fstab
# /swapfile none swap sw 0 0

# 查看 swap
swapon --show
free -h

# 关闭 swap
sudo swapoff /swapfile
```
