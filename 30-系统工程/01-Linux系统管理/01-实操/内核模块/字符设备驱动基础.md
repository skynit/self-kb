# 字符设备驱动基础

## 什么是字符设备

字符设备（Character Device）以**字节流**方式访问的设备，数据不经过缓冲，按顺序逐字节处理。

典型字符设备：
- 串口（`/dev/ttyS0`）
- 键盘、鼠标
- 帧缓冲（`/dev/fb0`）
- 自定义虚拟设备

> 与之对比：块设备（Block Device）以块为单位访问，支持随机读写（如硬盘 `/dev/sda`）。

---

## 设备号

每个设备由**主设备号 + 次设备号**唯一标识：

```
主设备号（Major）：标识驱动程序
次设备号（Minor）：标识该驱动管理的具体设备实例

ls -la /dev/
crw-rw---- 1 root video 29, 0 Jul  1 10:00 fb0
                ^       ^  ^
                类型    主  次
```

### 分配设备号

```c
#include <linux/fs.h>

dev_t devno;  // 设备号类型（主+次合并）

// 方法一：静态指定
#define MY_MAJOR 200
#define MY_MINOR 0
devno = MKDEV(MY_MAJOR, MY_MINOR);
register_chrdev_region(devno, 1, "mydevice");

// 方法二：动态分配（推荐）
alloc_chrdev_region(&devno, 0, 1, "mydevice");
// 参数：起始设备号, 次设备号起始, 数量, 名称
```

### 查看/释放设备号

```c
// 获取主次设备号
int major = MAJOR(devno);
int minor = MINOR(devno);

// 释放设备号
unregister_chrdev_region(devno, 1);
```

## 字符设备注册（新接口 cdev）

### 核心数据结构

```c
#include <linux/cdev.h>

struct cdev my_cdev;  // 字符设备结构体
```

### 注册流程

```c
// 1. 分配设备号
dev_t devno;
alloc_chrdev_region(&devno, 0, 1, "mydevice");

// 2. 初始化 cdev
cdev_init(&my_cdev, &fops);  // fops 是 file_operations 结构体

// 3. 添加 cdev 到内核
cdev_add(&my_cdev, devno, 1);

// 4. 创建设备节点（用户空间可见）
// 方法一：手动创建
// sudo mknod /dev/mydevice c 200 0

// 方法二：自动创建（使用 class + device）
```

### 注销流程（与注册相反）

```c
cdev_del(&my_cdev);                      // 1. 删除 cdev
unregister_chrdev_region(devno, 1);      // 2. 释放设备号
```

## file_operations 结构体

这是字符设备驱动的**核心**，定义了设备支持的所有操作：

```c
#include <linux/fs.h>

static int my_open(struct inode *inode, struct file *filp)
{
    printk(KERN_INFO "mydevice: opened\n");
    return 0;
}

static int my_release(struct inode *inode, struct file *filp)
{
    printk(KERN_INFO "mydevice: closed\n");
    return 0;
}

static ssize_t my_read(struct file *filp, char __user *buf,
                       size_t count, loff_t *f_pos)
{
    // 从设备读数据到用户空间 buf
    // 返回实际读取的字节数，或负数表示错误
    return count;
}

static ssize_t my_write(struct file *filp, const char __user *buf,
                        size_t count, loff_t *f_pos)
{
    // 从用户空间 buf 写数据到设备
    // 返回实际写入的字节数，或负数表示错误
    return count;
}

// file_operations 结构体
static const struct file_operations fops = {
    .owner   = THIS_MODULE,
    .open    = my_open,
    .release = my_release,
    .read    = my_read,
    .write   = my_write,
};
```

### 常用操作

| 操作 | 触发时机 | 说明 |
|------|----------|------|
| `.open` | `open()` 系统调用 | 打开设备 |
| `.release` | `close()` 系统调用 | 关闭设备 |
| `.read` | `read()` 系统调用 | 从设备读数据 |
| `.write` | `write()` 系统调用 | 向设备写数据 |
| `.llseek` | `lseek()` 系统调用 | 移动文件指针 |
| `.unlocked_ioctl` | `ioctl()` 系统调用 | 设备特定控制命令 |
| `.mmap` | `mmap()` 系统调用 | 内存映射 |
| `.poll` | `poll()/select()` | I/O 多路复用 |

## 用户空间与内核空间数据交换

**不能直接用 `memcpy`**，必须用专用函数：

```c
#include <linux/uaccess.h>

// 内核 → 用户（read 操作）
unsigned long copy_to_user(void __user *to, const void *from, unsigned long n);

// 用户 → 内核（write 操作）
unsigned long copy_from_user(void *to, const void __user *from, unsigned long n);
```

示例：
```c
static ssize_t my_read(struct file *filp, char __user *buf,
                       size_t count, loff_t *f_pos)
{
    char data[] = "Hello from kernel!";
    size_t len = sizeof(data);

    if (count < len)
        len = count;

    if (copy_to_user(buf, data, len))
        return -EFAULT;  // 复制失败

    *f_pos += len;
    return len;
}
```

> ⚠️ 为什么不能直接访问用户空间指针？因为用户空间地址可能无效、可能被换出、可能是恶意地址。`copy_to/from_user` 会做安全检查。

## 自动创建设备节点

手动 `mknod` 太麻烦，用 `class_create` + `device_create` 自动在 `/dev/` 下创建：

```c
#include <linux/device.h>

static struct class *my_class;
static struct device *my_device;

// 在模块初始化中
my_class = class_create("myclass");                    // 创建设备类
my_device = device_create(my_class, NULL, devno, NULL, "mydevice");  // 创建设备节点

// 在模块退出中
device_destroy(my_class, devno);
class_destroy(my_class);
```

效果：`/dev/mydevice` 自动出现，用户可以直接 `open("/dev/mydevice", ...)`。

## 完整最小字符设备驱动

```c
// simple_char.c
#include <linux/module.h>
#include <linux/fs.h>
#include <linux/cdev.h>
#include <linux/device.h>
#include <linux/uaccess.h>

static dev_t devno;
static struct cdev my_cdev;
static struct class *my_class;

static int my_open(struct inode *inode, struct file *filp)
{
    return 0;
}

static ssize_t my_read(struct file *filp, char __user *buf,
                       size_t count, loff_t *f_pos)
{
    char *msg = "Hello from kernel!\n";
    size_t len = strlen(msg) + 1;

    if (*f_pos >= len) return 0;
    if (count > len - *f_pos) count = len - *f_pos;

    if (copy_to_user(buf, msg + *f_pos, count))
        return -EFAULT;

    *f_pos += count;
    return count;
}

static const struct file_operations fops = {
    .owner = THIS_MODULE,
    .open  = my_open,
    .read  = my_read,
};

static int __init simple_char_init(void)
{
    alloc_chrdev_region(&devno, 0, 1, "simple_char");
    cdev_init(&my_cdev, &fops);
    cdev_add(&my_cdev, devno, 1);
    my_class = class_create("simple_char");
    device_create(my_class, NULL, devno, NULL, "simple_char");
    return 0;
}

static void __exit simple_char_exit(void)
{
    device_destroy(my_class, devno);
    class_destroy(my_class);
    cdev_del(&my_cdev);
    unregister_chrdev_region(devno, 1);
}

module_init(simple_char_init);
module_exit(simple_char_exit);
MODULE_LICENSE("GPL");
```

```bash
# 编译加载
make && sudo insmod simple_char.ko

# 验证设备节点
ls -la /dev/simple_char

# 测试读取
cat /dev/simple_char
# 输出：Hello from kernel!
```

## 关键概念总结

| 概念 | 说明 |
|------|------|
| 字符设备 | 以字节流方式访问的设备 |
| 设备号 | 主设备号（标识驱动）+ 次设备号（标识实例） |
| cdev | 字符设备内核结构体 |
| file_operations | 定义设备支持的操作（open/read/write/close 等） |
| copy_to_user | 内核空间 → 用户空间安全复制 |
| copy_from_user | 用户空间 → 内核空间安全复制 |
| class_create | 创建设备类（/sys/class/ 下出现目录） |
| device_create | 创建设备节点（/dev/ 下出现文件） |
| alloc_chrdev_region | 动态分配设备号（推荐） |
| register_chrdev_region | 静态指定设备号 |
