# 内核模块参数

## 什么是模块参数

模块参数允许在**加载模块时**从命令行传递值，也可以在运行时通过 sysfs 修改。类似于给程序传命令行参数。

---

## 基本用法

### 定义参数

```c
#include <linux/module.h>
#include <linux/moduleparam.h>
#include <linux/kernel.h>

// 普通变量
static int count = 1;
static char *name = "default";
static int array[3] = {1, 2, 3};

// 声明模块参数
module_param(count, int, 0644);           // 变量名, 类型, 权限
module_param(name, charp, 0644);          // charp = char pointer
module_param_array(array, int, NULL, 0644); // 数组参数

// 参数描述（可选但推荐）
MODULE_PARM_DESC(count, "Number of iterations");
MODULE_PARM_DESC(name, "Module name string");
MODULE_PARM_DESC(array, "An array of integers");
```

### 支持的类型

| 类型 | 含义 | 示例 |
|------|------|------|
| `int` | 整数 | `module_param(val, int, 0644)` |
| `long` | 长整数 | `module_param(val, long, 0644)` |
| `short` | 短整数 | `module_param(val, short, 0644)` |
| `uint` | 无符号整数 | `module_param(val, uint, 0644)` |
| `ulong` | 无符号长整数 | `module_param(val, ulong, 0644)` |
| `ushort` | 无符号短整数 | `module_param(val, ushort, 0644)` |
| `charp` | 字符串指针 | `module_param(str, charp, 0644)` |
| `bool` | 布尔值 | `module_param(flag, bool, 0644)` |

---

## 加载时传参

```bash
# 单个参数
sudo insmod hello.ko count=5 name="mytest"

# 数组参数
sudo insmod hello.ko array=10,20,30

# 查看参数
cat /sys/module/hello/parameters/count
cat /sys/module/hello/parameters/name
```

---

## 权限控制

权限参数控制 `/sys/module/<name>/parameters/<param>` 文件的访问权限：

| 权限 | 含义 |
|------|------|
| `0644` | 所有者可读写，其他人只读（运行时可修改） |
| `0444` | 只读（运行时不可修改） |
| `0666` | 所有人可读写 |
| `0000` | 在 sysfs 中不可见 |

> ⚠️ 只有设置了写权限的参数才能在运行时通过 sysfs 修改，无需卸载模块。

### 运行时修改参数

```bash
# 需要 root 权限
echo 10 > /sys/module/hello/parameters/count

# 验证
cat /sys/module/hello/parameters/count
```

## 参数回调（高级）

可以为参数设置**变更通知回调**，当参数被修改时执行自定义逻辑：

```c
static int count = 1;

// 参数变更回调函数
static int count_set(const char *val, const struct kernel_param *kp)
{
    int res = param_set_int(val, kp);  // 先用默认处理设置值
    if (res == 0) {
        printk(KERN_INFO "count changed to %d\n", count);
        // 在这里做额外的处理，比如更新硬件寄存器
    }
    return res;
}

// 使用 ops 结构体注册回调
static const struct kernel_param_ops count_ops = {
    .set = count_set,
    .get = param_get_int,    // 读取时用默认处理
};

module_param_cb(count, &count_ops, &count, 0644);
```

## 完整示例

```c
// param_demo.c
#include <linux/module.h>
#include <linux/moduleparam.h>
#include <linux/kernel.h>

static int debug_level = 1;
static char *device_name = "mydevice";
static int baud_rate = 9600;

module_param(debug_level, int, 0644);
MODULE_PARM_DESC(debug_level, "Debug verbosity level (0-3)");

module_param(device_name, charp, 0644);
MODULE_PARM_DESC(device_name, "Name of the device");

module_param(baud_rate, int, 0444);
MODULE_PARM_DESC(baud_rate, "Serial baud rate (read-only)");

static int __init param_demo_init(void)
{
    printk(KERN_INFO "param_demo: debug_level=%d, device=%s, baud=%d\n",
           debug_level, device_name, baud_rate);
    return 0;
}

static void __exit param_demo_exit(void)
{
    printk(KERN_INFO "param_demo: unloaded\n");
}

module_init(param_demo_init);
module_exit(param_demo_exit);
MODULE_LICENSE("GPL");
```

```bash
# 加载时传参
sudo insmod param_demo.ko debug_level=3 device_name="ttyS0" baud_rate=115200

# 查看参数
cat /sys/module/param_demo/parameters/debug_level   # 3
cat /sys/module/param_demo/parameters/device_name   # ttyS0
cat /sys/module/param_demo/parameters/baud_rate     # 115200（只读，不能修改）

# 运行时修改可写参数
echo 0 > /sys/module/param_demo/parameters/debug_level
```

## 注意事项

| 要点 | 说明 |
|------|------|
| 字符串参数 | `charp` 类型的参数，内核会分配内存，模块卸载时**不会自动释放** |
| 只读保护 | 不希望被运行时修改的参数用 `0444` 权限 |
| 数组参数 | 第四个参数是 `&arr_argc`（实际传入的元素数），可传 `NULL` |
| 重启失效 | 模块参数在卸载后丢失，不会持久化 |
