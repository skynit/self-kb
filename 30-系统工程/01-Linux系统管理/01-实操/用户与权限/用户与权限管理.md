# 用户与权限管理

## 用户管理

### useradd — 创建用户

```bash
sudo useradd username                        # 创建用户（默认无家目录）
sudo useradd -m username                     # 创建用户并建家目录
sudo useradd -m -s /bin/bash username        # 指定 shell
sudo useradd -m -G sudo,docker username      # 指定附加组
sudo useradd -m -u 1500 username             # 指定 UID
```

### adduser — 创建用户（交互式，Debian/Ubuntu）

```bash
sudo adduser username               # 交互式创建，自动建家目录、设密码
```

### usermod — 修改用户

```bash
sudo usermod -aG docker username    # 添加附加组（-a 追加，不覆盖）
sudo usermod -s /bin/zsh username   # 修改 shell
sudo usermod -l newname oldname     # 修改用户名
sudo usermod -L username            # 锁定账户
sudo usermod -U username            # 解锁账户
```

### userdel — 删除用户

```bash
sudo userdel username               # 删除用户（保留家目录）
sudo userdel -r username            # 删除用户和家目录
```

### passwd — 密码管理

```bash
sudo passwd username                # 设置/修改用户密码
passwd                              # 修改自己的密码
sudo passwd -l username             # 锁定密码
sudo passwd -u username             # 解锁密码
sudo chage -l username              # 查看密码策略
sudo chage -M 90 username           # 密码最长有效期90天
```

## 组管理

```bash
sudo groupadd groupname             # 创建组
sudo groupdel groupname             # 删除组
sudo groupmod -n newname oldname    # 重命名组
groups username                     # 查看用户所属组
id username                         # 查看用户 UID、GID 和所有组
```

### /etc/group 文件

```
groupname:x:GID:user1,user2
```

## sudo — 提权

```bash
sudo command                        # 以 root 权限执行单条命令
sudo -u username command            # 以指定用户身份执行
sudo -i                             # 切换到 root 的交互式 shell
sudo su                             # 切换到 root
sudo visudo                         # 安全编辑 /etc/sudoers
```

### sudoers 配置

```
# /etc/sudoers（用 visudo 编辑，不要直接 vim）

# 允许用户执行所有命令
username ALL=(ALL:ALL) ALL

# 允许组执行所有命令
%sudo ALL=(ALL:ALL) ALL

# 免密执行（不推荐用于生产）
username ALL=(ALL) NOPASSWD: ALL

# 只允许特定命令
username ALL=(ALL) /usr/bin/systemctl, /usr/bin/journalctl
```

> ⚠️ 永远用 `visudo` 编辑 sudoers，它会做语法检查。直接编辑可能导致 sudo 完全失效。

## 文件权限详解

### 权限表示

```
-rwxr-xr-x 1 user group 4096 Jan 1 00:00 file
 │││ │││ │││
 │││ │││ ││└── 其他人：r-- = 4+0+0 = 4
 │││ │││ └┘── 组：r-x = 4+0+1 = 5
 │││ └┘└── 所有者：rwx = 4+2+1 = 7
 └┘└── 文件类型（- 普通文件，d 目录，l 链接）
```

### chmod — 权限修改

```bash
# 数字模式
chmod 755 file                  # rwxr-xr-x
chmod 644 file                  # rw-r--r--
chmod 600 file                  # rw-------（SSH 密钥推荐）

# 符号模式
chmod u+x file                  # 所有者加执行权限
chmod g-w file                  # 组去掉写权限
chmod o= file                   # 其他人无权限
chmod a+r file                  # 所有人加读权限
chmod u=rwx,g=rx,o= file        # 一次性设置

# 递归
chmod -R 755 dir/
```

### chown — 所有权修改

```bash
chown user file                 # 修改所有者
chown user:group file           # 修改所有者和组
chown :group file               # 只修改组
chown -R user:group dir/        # 递归修改
```

### 特殊权限

```bash
# SUID（4）：执行时以文件所有者身份运行
chmod u+s /usr/bin/passwd       # passwd 需要 root 权限修改 /etc/shadow
chmod 4755 file                 # 数字表示

# SGID（2）：执行时以文件组身份运行；目录下新建文件继承组
chmod g+s dir/
chmod 2755 dir/

# Sticky Bit（1）：目录中只有文件所有者能删除自己的文件
chmod +t /tmp                   # /tmp 就是典型例子
chmod 1777 /tmp
```

## umask — 默认权限掩码

```bash
umask                           # 查看当前 umask（如 0022）
umask 0027                      # 设置 umask

# 权限计算：
# 文件默认权限 = 666 - umask = 666 - 022 = 644 (rw-r--r--)
# 目录默认权限 = 777 - umask = 777 - 022 = 755 (rwxr-xr-x)
```

## 重要配置文件

| 文件 | 内容 |
|------|------|
| `/etc/passwd` | 用户信息（用户名:密码占位:UID:GID:描述:家目录:shell） |
| `/etc/shadow` | 加密密码（仅 root 可读） |
| `/etc/group` | 组信息 |
| `/etc/sudoers` | sudo 权限配置 |
| `/etc/login.defs` | 登录默认设置（密码策略、UID 范围等） |

## 查看用户信息

```bash
whoami                          # 当前用户名
who                             # 当前登录的用户
w                               # 当前登录用户及活动
last                            # 最近登录记录
lastlog                         # 所有用户最后登录时间
id                              # 当前用户的 UID/GID/组
id username                     # 指定用户信息
```
