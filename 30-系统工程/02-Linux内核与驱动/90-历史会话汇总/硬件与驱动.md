# 硬件与驱动

> 来源：OpenCode 历史会话 | ~8 条

## 显卡类型获取

```bash
lspci | grep -E "VGA|3D"
glxinfo | grep "OpenGL renderer"
lshw -c display
```

输出示例：
```
00:02.0 VGA compatible controller: Intel Corporation ...
OpenGL renderer string: Mesa Intel Graphics (ADL GT2)
```

## 华为 MateBook D14 驱动

华为笔记本 Linux 驱动情况：
- 部分硬件（指纹传感器、WiFi 特殊型号）缺少官方 Linux 驱动
- 社区驱动来源：AUR、GitHub
- 需要在 `lsusb` / `lspci` 确认硬件 ID 后搜索

## 指纹传感器

华为笔记本指纹传感器（如 GDIX51C0）Linux 驱动稀缺。

排查步骤：
```bash
lsusb                          # 查看 USB 设备列表
# 找指纹传感器条目，如：
# Bus 003 Device 002: ID 27c6:5125 Shenzhen Goodix Technology Co.,Ltd.

lsusb -v -d 27c6:5125          # 详细硬件信息
```

驱动来源：
- libfprint 支持列表：https://fprint.freedesktop.org/supported-devices.html
- AUR 搜索：`yay -Ss GDIX51C0`
- GitHub 搜索硬件 ID

## 无线鼠标连接

- **蓝牙鼠标**：
  ```bash
  bluetoothctl
  scan on
  pair <MAC>
  connect <MAC>
  ```
  检查 `systemctl status bluetooth`

- **2.4GHz 接收器鼠标**：
  - 确认接收器连接正常
  - `lsusb` 检查是否识别
  - 检查电池电量
