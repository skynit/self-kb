# 通用知识与工具

> 来源：OpenCode 历史会话 | ~15 条

## SBOM

Software Bill of Materials（软件物料清单）：
- 列出软件所有组件、依赖、许可证信息
- 用于供应链安全与合规
- 格式：SPDX、CycloneDX
- 重要性：Log4j 等漏洞爆发时快速定位受影响组件

## luna / terra

- **luna**：拉丁语"月亮"（→ lunar 月球的）
- **terra**：拉丁语"大地/地球"（→ terrestrial 陆地的、territory 领土）
- **金属**英文：metal

## Corepack

Node.js 内置的包管理器管理工具（pnpm/yarn 版本管理）。

```bash
# 未找到命令
npm install -g corepack
# 或升级 Node.js（v16.9+）
```

## dms 窗口透明

dms（display manager service）：lightdm/sddm 等显示管理器。
窗口透明原因：
- 合成器设置
- 主题配置导致背景透明

## Firefox 问题

| 问题 | 排查 |
|------|------|
| 内存泄漏 | `about:memory` 诊断 |
| 重启后数据丢失 | 检查 profile 目录权限 |
| 标签页无限打开 | 扩展或恶意脚本问题 |
| 标签页自动无限生成 | 检查已安装扩展、安全模式启动 |

## WindTerm-bin AUR 构建

构建失败原因：
- 校验和不匹配
- 依赖问题
- 解决方法：检查 AUR 页面评论、手动修改 PKGBUILD

## 剪贴板错误

`Cannot read 'clipboard'`：
- 浏览器安全策略（需用户交互触发）
- Wayland 下剪贴板协议不兼容
- Electron 应用需添加 `--enable-features=UseOzonePlatform --ozone-platform=wayland`

## Thunar 注册超时

Thunar 文件管理器 DBus 注册超时：
- `dbus-daemon` 未运行
- 系统资源紧张
- 重启 dbus：`systemctl --user restart dbus`

## CasaOS git clone 问题

fetch-pack EOF 错误：
- 网络不稳定
- 代理超时
- `git config --global http.postBuffer 524288000`

## Hoppscotch / Postman

API 调试工具：
- AUR 安装/卸载
- deb 包安装
- AUR 多个包的区分

## spawn-sh-at-startup dbus

桌面环境启动时通过 D-Bus 激活服务运行 shell 命令。
与 `~/.config/autostart/` 中的 `.desktop` 文件类似。

## api.botcf.com 返回 HTML

脚本 URL 返回 HTML → 服务端配置错误，未正确返回纯文本脚本内容。
检查 URL 路径和服务器配置。
