# 子复母仇

## 洞察

五行相克之中存在"反制"之理，三命通会论五行生克中称之为"子复母仇"：

当A克B时，B所生之子C（即B之子）反过来克A（施克者）。此即"母仇子报"之理。

- 金克木 → 木生火 → 火克金（子复母仇）
- 木克土 → 土生金 → 金克木
- 土克水 → 水生木 → 木克土
- 水克火 → 火生土 → 土克水
- 火克金 → 金生水 → 水克火

此理揭示五行生克并非单向压制，而是循环制约的动态平衡。在命理实践中，被克之五行所生之子（食伤）往往是化解克害的关键力量。
