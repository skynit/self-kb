# 调候取用

> 属于 [[50-命理/00-Meta/取用神体系MOC]] | 相关：[[用神总论]]、[[调候体系MOC]]

## 定义

调候取用者，**调节命局寒暖燥湿**之法也。人禀天地之气以生，命局过寒则万物不生，过暖则万物焦枯，过湿则万物腐朽，过燥则万物枯竭。须以调候之神，使命局寒暖适中、燥湿得宜，方能生发万物。

《穷通宝鉴》开宗明义：

> 天道有寒暖，地道有燥湿，人道有顺逆。寒暖燥湿者，天时之常也。
> —— [[穷通宝鉴]]·行281-300

## 详解

### 调候之原理

人禀天地之气以生，出生之月份即为所禀气候之根源。夏月生人，命局偏暖偏燥；冬月生人，命局偏寒偏湿。此为先天气候之偏枯，须以调候之神补之。

《穷通宝鉴》以日主五行配合月令，逐月详论调候之需：

| 月令 | 气候特征 | 调候需求 |
|------|----------|----------|
| 寅月 | 余寒犹存 | 须火温暖，丙火为主 |
| 卯月 | 春暖渐至 | 火水既济方佳 |
| 辰月 | 春深土润 | 须火暖土，水火并用 |
| 巳月 | 初夏渐热 | 须水润泽，壬癸为主 |
| 午月 | 盛夏极热 | 调候为急，专用水润 |
| 未月 | 夏末土燥 | 须水润土，金水并用 |
| 申月 | 初秋渐凉 | 须火暖金，水火并用 |
| 酉月 | 秋深金旺 | 须火炼金，丙丁为主 |
| 戌月 | 秋末土燥 | 须水润土，壬癸为主 |
| 亥月 | 初冬渐寒 | 须火温暖，丙火为主 |
| 子月 | 隆冬极寒 | 调候为急，必用丙火 |
| 丑月 | 冬末余寒 | 须火解冻，丙丁为主 |

### 夏月调候

> 夏月极热，须水以润之。无水则万物焦枯，虽有财官印绶，亦难发达。
> —— [[穷通宝鉴]]·行3435-3437

夏月（巳午未月）生人，命局偏暖偏燥，调候第一要务为**用水**：

- **壬水**：大江大河之水，润泽之力最强，为夏月调候上选
- **癸水**：雨露之水，润泽之力次之，亦可用

> 夏月用壬调候，如久旱逢甘霖，万物复苏。若无壬水，癸水亦可，但力弱。
> —— [[穷通宝鉴]]·甲木夏月论

夏月调候之重要性：

> 夏月无水，虽有金木火土，格局配合再好，亦难发达。调候为先，格局为后。
> —— [[穷通宝鉴]]·总论

### 冬月调候

> 严冬调候为急，必用丙火。无丙则万物闭塞，虽有财官印绶，亦难生发。
> —— [[穷通宝鉴]]·行10360-10364

冬月（亥子丑月）生人，命局偏寒偏湿，调候第一要务为**用火**：

- **丙火**：太阳之火，温暖之力最强，为冬月调候上选
- **丁火**：灯烛之火，温暖之力次之，但冬月用丁力弱

> 冬月用丙调候，如寒冬得太阳，万物解冻。若无丙火，丁火力弱，须甲木生之。
> —— [[穷通宝鉴]]·甲木冬月论

冬月调候之重要性：

> 冬月无火，虽有金木水土，格局配合再好，亦难发达。调候为先，格局为后。
> —— [[穷通宝鉴]]·总论

### 调候与十干配合

《穷通宝鉴》以十干配合十二月，逐月详论调候之需。以甲木为例：

| 月份 | 甲木调候 | 核心用神 |
|------|----------|----------|
| 正月（寅） | 丙火为主，癸水为佐 | 丙癸 |
| 二月（卯） | 庚金为主，丙丁壬癸为佐 | 庚 |
| 三月（辰） | 庚金为主，壬水为佐 | 庚壬 |
| 四月（巳） | 癸水为主，丁火为佐 | 癸丁 |
| 五月（午） | 癸水为主，庚辛为佐 | 癸 |
| 六月（未） | 癸水为主，庚辛为佐 | 癸庚 |
| 七月（申） | 庚金为主，丁火为佐 | 庚丁 |
| 八月（酉） | 庚金为主，丁火为佐 | 庚丁 |
| 九月（戌） | 庚金为主，甲木为佐 | 庚甲 |
| 十月（亥） | 庚金为主，丁火丙火为佐 | 庚丁丙 |
| 十一月（子） | 丁火为主，庚金为佐 | 丁庚 |
| 十二月（丑） | 丁火为主，庚金为佐 | 丁庚 |

> 以上为甲木调候大要，余九干仿此。详见 [[穷通宝鉴]]各干总论。

## 调候与扶抑之关系

调候与扶抑为取用之两大法门，二者之关系须明辨：

### 调候优先

> 调候为急，格局次之。
> —— [[穷通宝鉴]]·行1158

在特定情况下，调候优先于扶抑：

- **夏月极热**：即使日主弱须扶，亦须先用水调候
- **冬月极寒**：即使日主旺须抑，亦须先用火调候

> 命局过寒过暖，虽日主旺衰分明，须以调候为先。调候得宜，再论扶抑。
> —— [[滴天髓阐微]]·气候章·任铁樵注

### 调候与扶抑并重

多数情况下，调候与扶抑须并重：

> 命局寒暖适中，燥湿得宜，则以扶抑为用。命局寒暖偏枯，燥湿失调，则以调候为先，扶抑为后。
> —— [[滴天髓阐微]]·用神章

### 调候用神与其他用神合一

最妙者，调候用神与扶抑用神、格局用神合而为一：

> 用神有三：格局用神、扶抑用神、调候用神。三者合一，上上之命；三者二合，中上之命；三者各异，须分主次。
> —— [[子平真诠]]·论用神

## 调候之注意事项

### 一、不可太过

调候之神须适中，太过则反为害：

> 夏月用水调候，水太多则寒。冬月用火调候，火太多则燥。
> —— [[穷通宝鉴]]·总论

### 二、须分真假

调候有真假之分：

> 真调候者，用神得力，寒暖适中。假调候者，用神无力，杯水车薪。
> —— [[滴天髓阐微]]·气候章·任铁樵注

### 三、须看节气深浅

同一个月，节气深浅不同，调候需求亦异：

> 寅月初尚余寒，须丙火为主；寅月末春暖渐至，丙火次之。
> —— [[穷通宝鉴]]·甲木正月论
