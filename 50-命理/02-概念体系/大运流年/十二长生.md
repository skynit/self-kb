# 十二长生

> 属于 [[大运总论]] | 相关：[[五行总论]]、[[天干总论]]

## 定义

十二长生者，以天干在十二地支中的**旺衰状态**，分为长生、沐浴、冠带、临官、帝旺、衰、病、死、墓、绝、胎、养十二个阶段。此十二阶段模拟万物从出生到死亡再到重生的完整生命周期，是判断天干力量强弱的重要依据。

## 详解

### 十二阶段释义

《渊海子平》逐一解释十二长生之含义：

> **长生者**，言物在於发生而出，如人受父母精血延怀十月而生也。
>
> **沐浴者**，乃生之初，在地正、在天弱之中，如人生出沐浴盆中，未可言吉。
>
> **冠带者**，物之长成道，能运用，如人之顶冠束带，以召其用。
>
> **临官者**，言物盛，如人之用谋为而有卓立也。
>
> **帝旺者**，言物有操持可立，如人之受君禄，乘权衡任天位，精神康泰，得其所以。
>
> **衰者**，言物之将老，如人之精血耗散而身体劳倦。
>
> **病者**，言物之有皆好，如人之有病也。
>
> **胎者**，言物伏於内而未明，如人之存母腹，以受气。
>
> **养者**，言万物生长，如人之出於妇腹始为人也。
> —— [[渊海子平]]（行2150-2172）

《渊海子平》进一步总结吉凶：

> 但指金木水火土言，以人寓其意。但逢长生、冠带、临官、帝旺为吉，但逢沐浴、衰、病为不吉也。至於死、绝，如无救助者直为凶矣。胞胎受气亦为半吉，养亦如之周而复始，其理可推。
> —— [[渊海子平]]（行2168-2172）

### 阳干顺行，阴干逆转

十二长生的排列有一重要规则：**阳干顺行，阴干逆转**。

**阳干顺行**：甲丙戊庚壬五阳干，按地支顺序（子丑寅卯……）顺排十二长生。

以甲木为例：
```
长生在亥 → 沐浴在子 → 冠带在丑 → 临官在寅 → 帝旺在卯
→ 衰在辰 → 病在巳 → 死在午 → 墓在未 → 绝在申 → 胎在酉 → 养在戌
```

**阴干逆转**：乙丁己辛癸五阴干，按地支顺序逆排十二长生。

以乙木为例：
```
长生在午 → 沐浴在巳 → 冠带在辰 → 临官在卯 → 帝旺在寅
→ 衰在丑 → 病在子 → 死在亥 → 墓在戌 → 绝在酉 → 胎在申 → 养在未
```

> 阳干顺行，阴干逆转，此定法也。
> —— [[渊海子平]]·论天干生旺死绝

### 十二长生与大运的关系

《渊海子平》论大运行十二长生宫之吉凶：

> 凡行运长生，主有创建作新之事。到临官帝旺，主兴盛、快乐、发福、进财、生子、骨肉之庆。到衰病之乡，多退败、破财、疾病等事。到死绝乡，主骨肉死丧、自身衰祸、钝闷百事蹇塞。到败运，主落魄、懒惰、酒色、昏迷。到胎库成形冠带之乡，百事得中、安康、平易。
> —— [[渊海子平]]（行15113-15117）

大运行至不同十二长生宫位，吉凶各异：

| 大运宫位 | 主事 | 说明 |
|----------|------|------|
| **长生** | 创建、开创基业 | 如人初生，一切从头开始 |
| **沐浴** | 落魄、酒色昏迷 | 如人沐浴，赤裸无防 |
| **冠带** | 渐进、成长 | 如人加冠，渐入佳境 |
| **临官** | 兴盛、发达 | 如人出仕，事业有成 |
| **帝旺** | 极盛、巅峰 | 如人登极，荣耀之至 |
| **衰** | 退败、渐衰 | 气始退，事多不顺 |
| **病** | 困顿、多事 | 如人有病，处处受制 |
| **死** | 丧祸、大凶 | 气已绝，主凶事 |
| **墓** | 收藏、停滞 | 气入库，事多阻滞 |
| **绝** | 断绝、极凶 | 气全无，主大凶 |
| **胎** | 孕育、潜伏 | 新机萌动，尚未成形 |
| **养** | 滋养、准备 | 事得中平，安康平易 |

### 大运曾历长生之论

《渊海子平》特别指出，大运若曾经历日主之长生宫位，则命主气盛，即使岁运来冲克，为祸亦不重：

> 大运曾历过本命长生处者，谓之气盛之运，虽岁运来冲克者，为祸不重，运气强故也。未经长生而岁运刑冲克破，则便为灾，盖气未备运弱故也。
> —— [[渊海子平]]（行15105-15107）

此论揭示了十二长生在大运中的实际应用：命主若曾在好运（长生、临官、帝旺）中积蓄了足够的气运，则即使后运行至衰病死绝之地，亦有余力抵御灾咎。

## 十二长生在四柱不同位置的含义差异

十二长生在年柱、月柱、日柱、时柱上的含义各有侧重，不可一概而论。

### 年柱

年柱代表祖上根基与早年运势。十二长生在年柱，主祖上之旺衰与幼年之环境。如甲木长生在亥，若年支为亥，则祖上有生发之气，幼年环境尚可。若年支为甲木之绝地（申），则祖业凋零，早年多困。

### 月柱

月柱为命局提纲，权重最重。十二长生在月柱，决定日主的根本旺衰。如甲木生于寅月（临官），日主得令，根基深厚；若生于申月（绝地），日主失令，根基浅薄。月柱的十二长生状态是判断日主强弱的首要依据。

### 日柱

日柱代表自身与配偶。日支的十二长生状态反映日主的内在状态。如甲木坐寅（临官），为"坐禄"，自身根基稳固，精力充沛。如甲木坐申（绝地），为"坐绝"，自身底气不足，须依赖外力扶助。

### 时柱

时柱代表子女与晚年。十二长生在时柱，主晚年之归宿与子女之缘。如甲木时支为卯（帝旺），晚年精力尚旺，子女有出息。如甲木时支为午（死地），晚年渐衰，子女缘薄。

### 综合判断

实际推命中，四柱的十二长生状态须综合判断。如日主甲木，月令寅（临官）、日支卯（帝旺）、时支辰（衰），则日主早年得力、中年极旺、晚年渐衰——此为正常的人生节奏。若月令申（绝）、日支酉（胎）、时支戌（养），则日主早年困顿、中年孕育、晚年渐养——先苦后甜之命。

## 十二长生在大运中的应用实例

十二长生在大运中的应用，是判断运程吉凶的重要技术。

### 实例一：行临官帝旺运

日主甲木身弱，大运至寅（临官）、卯（帝旺）之地。此二运为日主得力之时，主事业兴盛、财源广进、身体康健。若命局中用神为木，则此二运为一生中最辉煌的阶段。

> 凡行运长生，主有创建作新之事。到临官帝旺，主兴盛、快乐、发福、进财、生子、骨肉之庆。
> —— [[渊海子平]]（渊海子平行15113-15117）

### 实例二：行衰病死绝运

日主甲木身弱，大运至辰（衰）、巳（病）、午（死）、未（墓）、申（绝）之地。此数运为日主失力之时，主事业退败、疾病缠身、破财连连。尤其行至死绝之地，若无救助，主骨肉死丧、自身衰祸。

### 实例三：气盛之运的缓冲效应

《渊海子平》特别指出：大运若曾经历日主之长生宫位，则命主气盛，即使岁运来冲克，为祸亦不重。

> 大运曾历过本命长生处者，谓之气盛之运，虽岁运来冲克者，为祸不重，运气强故也。未经长生而岁运刑冲克破，则便为灾，盖气未备运弱故也。
> —— [[渊海子平]]（渊海子行15105-15107）

**实例**：日主甲木，早年行亥运（长生）、子运（沐浴）、丑运（冠带），在好运中积蓄了足够的气运。至申运（绝地），虽为凶运，但因早年气盛，灾咎减轻。反之，若早年未经长生，直接行至绝地，则灾祸立见。

### 实例四：败运之特殊表现

> 到败运，主落魄、懒惰、酒色、昏迷。
> —— [[渊海子平]]（渊海子行15115-15117）

败运即沐浴之运，此运之凶不在外在灾祸，而在内在堕落——命主意志消沉、沉迷酒色、判断失误。此运之害往往比外在灾祸更为深远，因为它侵蚀的是命主的心志与判断力。

## 阳干顺行阴干逆转的原理

十二长生的排列规则"阳干顺行，阴干逆转"，其原理根植于阴阳之理。

### 阴阳对待之理

阳干顺行，取阳气上升、向前推进之势。甲木为阳木，如参天大树，向上生长，故从亥（长生）顺行至卯（帝旺），一路向上。

阴干逆转，取阴气下降、向内收敛之势。乙木为阴木，如藤蔓花草，攀附蔓延，故从午（长生）逆行至寅（帝旺），反向运动。

### 阴阳互根

阳干死处即阴干生处，阴干死处即阳干生处。如甲木死于午，乙木生于午；乙木死于亥，甲木生于亥。此即阴阳互根之理——生与死、进与退，本为一体之两面。

> 阳干顺行，阴干逆转，此定法也。
> —— [[渊海子平]]·论天干生旺死绝

### 不可拘泥

《渊海子平》特别指出：论命切不可专泥于生旺而吉、衰败而凶也。如丙火绝于亥，表凶，然亥中藏甲木，木能生火，丙日亥时乃多贵格。如戊土旺于巳，兼又建禄，本作贵格，然巳中藏庚金（伤官），戊日巳时官终不显。故须以活法推之，不可死守教条。

> 议命岂可拘于生旺之说？举此二例，则议命切不可专泥于生旺而吉，衰败而凶也，又当以活法推之。
> —— [[渊海子平]]（渊海子平行5923-5931）

## 长生与建禄的辨析

长生与建禄（临官）虽同为十二长生中的吉位，但含义有别。

### 长生

长生者，气始发，如旭日东升。长生之五行虽力量尚弱，但上升之势不可阻挡，后劲十足。长生主"生发"、"萌动"、"新机"，适合开创、起步。

### 建禄（临官）

建禄者，气已旺，如壮年得志。建禄之五行力量充盈，根基深厚，是天干在地支中的本气旺位。建禄主"自立"、"根基"、"实力"，适合守成、发展。

> 建禄：天干在地支中的本气旺位，为自身根基最强处。
> —— [[渊海子平]]（渊海子行5972）

### 二者的实际差异

以甲木为例：
- **长生在亥**：甲木初生，如幼苗破土。亥中藏壬水（印绶），水能生木，甲木得母气滋养，根基虽浅但生机勃勃。
- **建禄在寅**：甲木已旺，如大树参天。寅中藏甲木本气，甲木坐于禄地，力量最强，自立自足。

长生之木如幼苗，虽弱而有无限可能；建禄之木如大树，虽强而上升空间有限。故长生之"后劲"胜于建禄之"当下"——此即"相妙于旺"之理在十二长生中的体现。

### 建禄格的特殊性

建禄格为命理学中的重要格局。月令为日主之建禄之地，日主得令身旺，不宜再行印比之运（生扶过旺），而宜行财官之运（抑制平衡）。此与长生之运喜生扶恰好相反——盖因长生时尚弱需扶，建禄时已旺需抑。
