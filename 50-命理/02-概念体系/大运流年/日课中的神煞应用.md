# 日课中的神煞应用

> 属于 [[日课推算法]] | 相关：[[神煞总论]]、[[天乙贵人]]、[[驿马]]、[[桃花]]

## 定义

日课中的神煞，指以**今日干支**作用于命局四柱时，所引动的各类吉神凶煞。神煞在日课中为辅助参考，可增添细节上的吉凶征兆，但不可作为主要判断依据。

> 论命之法，先推五行休旺格局，然后参以神煞，则吉凶无遗矣。
> —— [[渊海子平]]（渊海子行29405-29415）

---

## 基本原则：五行为主，神煞为辅

### 三层次序在日课中的应用

| 层次 | 主次 | 日课中的表现 |
|------|------|-------------|
| 第一层 | 格局 | 今日干支是否有利于用神、是否生扶日主 |
| 第二层 | 十神 | 今日天干所代表的十神性质（喜还是忌） |
| 第三层 | 神煞 | 今日是否引动吉神（贵人、文昌等）或凶煞（白虎、丧门等） |

> 神煞者，天地五行正行精气，各有所主吉凶。在各命中用之。
> —— [[渊海子平]]·论神煞

神煞之用，以格局为前提。格局好者，遇吉神锦上添花，遇凶煞亦不为大害；格局差者，遇凶煞雪上加霜，遇吉神亦杯水车薪。

> 君子格中也犯七煞阳刃，小人命内亦有正印官星。
> —— [[三命通会]]（三命通会行3644-3646）

## 日课常用吉神

### 一、天乙贵人

**含义**：命理十二神煞之首，所至之处一切凶煞隐然而避。日课中见天乙贵人，主当日有贵人相助、逢凶化吉。

**查法**：以日主天干查今日地支。

| 日干 | 贵人在 |
|:----:|:------:|
| 甲戊庚 | 丑、未 |
| 乙己 | 子、申 |
| 丙丁 | 亥、酉 |
| 壬癸 | 卯、巳 |
| 辛 | 寅、午 |

**口诀**：甲戊庚牛羊，乙己鼠猴乡，丙丁猪鸡位，壬癸兔蛇藏，辛逢虎马乡。

**日课应用**：今日地支为你的贵人位 → 宜求人办事、拜访上级、谈判签约。贵人之力须结合昼夜之分：昼生人喜昼贵，夜生人喜夜贵，得力更甚。

> 天乙者，乃天上之神……其神最尊贵，所至之处，一切凶煞隐然而避。
> —— [[三命通会]]·论天乙贵人

详见 [[天乙贵人]]。

### 二、文昌贵人

**含义**：主聪明智慧、学业文章。日课中见文昌，主当日利考试、写作、学习。

**查法**：以日主天干查今日地支。

| 日干 | 文昌在 |
|:----:|:------:|
| 甲 | 巳 |
| 乙 | 午 |
| 丙 | 申 |
| 丁 | 酉 |
| 戊 | 申 |
| 己 | 酉 |
| 庚 | 亥 |
| 辛 | 子 |
| 壬 | 寅 |
| 癸 | 卯 |

**口诀**：甲乙巳午报君知，丙戊申宫丁己鸡，庚猪辛鼠壬逢虎，癸人见兔入云梯。

**日课应用**：今日地支为你的文昌位 → 宜读书、考试、撰写文案、策划方案。

### 三、天德 / 月德

**含义**：天德月德为化解凶煞之吉神。日课中见天德月德，主当日逢凶化吉、灾祸减轻。

**天德查法**（以月支取）：

| 申 | 癸 |
| 酉 | 寅 |
| 戌 | 丙 |
| 亥 | 乙 |

| 丑 | 庚 |

**月德查法**（以月支取三合五行之阳干）：

| 月支 | 月德在 |
|:----:|:------:|
| 寅午戌 | 丙 |
| 申子辰 | 壬 |
| 亥卯未 | 甲 |
| 巳酉丑 | 庚 |

**日课应用**：今日天干为你的天德或月德 → 即使流年不利，当日亦有化解之力。特别适用于需要"化煞"的日子。

### 四、驿马

**含义**：主出行、迁移、变动。日课中见驿马，主当日有出行、变动、消息到来。

**查法**：以日支所属三合局取今日地支。

| 日支三合 | 驿马在 |
|:--------:|:------:|
| 寅午戌 | 申 |
| 申子辰 | 寅 |
| 巳酉丑 | 亥 |
| 亥卯未 | 巳 |

**日课应用**：今日地支为你的驿马位 → 宜出差、旅行、搬迁、洽谈。逢冲则动（今日地支又冲命局），主动荡更大；逢合则绊（今日地支与命局合），主想动而不得。

> 驿马者，三命中发用，喜庆之神。若人遇之，君子常居荣位，小人主丰赡。
> —— [[三命通会]]·论驿马

详见 [[驿马]]。

## 日课常用凶煞

### 一、流年十二神煞（以日课引动）

流年十二神煞以流年地支起排，逐年轮转。当日课干支与之发生冲合关系时，可引动相应神煞之兆。

| 神煞 | 吉凶 | 主事 | 引动条件 |
|------|:----:|------|----------|
| 太岁 | 中性 | 一年主宰 | 日课冲太岁主变动，合太岁主稳定 |
| 太阳 | 吉 | 喜庆贵人 | 日课引动太阳主当日有喜事 |
| 丧门 | 凶 | 丧服哭泣 | 日课冲合丧门主防丧事、悲伤 |
| 太阴 | 吉 | 暗助财帛 | 日课引动太阴主暗中有财或女贵人 |
| 官符 | 凶 | 官讼是非 | 日课冲合官符主防官讼、口舌 |
| 死符 | 凶 | 疾病灾厄 | 日课引动死符主防疾病、身体不适 |
| 岁破 | 凶 | 破败变动 | 日课冲合岁破主防破财、计划变动 |
| 龙德 | 吉 | 逢凶化吉 | 日课引动龙德主当日化险为夷 |
| 白虎 | 凶 | 血光横祸 | 日课冲合白虎主防血光、意外 |
| 福德 | 吉 | 福禄喜庆 | 日课引动福德主当日有福 |
| 吊客 | 凶 | 丧服吊唁 | 日课冲合吊客主防丧事 |
| 病符 | 凶 | 疾病 | 日课引动病符主防疾病 |

> 神煞，古有百二十名，其说穿凿支离，造化恐不如是。
> —— [[三命通会]]（三命通会行3504-3506）

### 二、桃花

**含义**：主情欲、异性缘、才华外露。日课中见桃花，主当日异性缘旺、人缘佳，但亦防沉迷。

**查法**：以日支所属三合局取桃花（即沐浴位）。

| 日支三合 | 桃花在 |
|:--------:|:------:|
| 寅午戌 | 卯 |
| 巳酉丑 | 午 |
| 申子辰 | 酉 |
| 亥卯未 | 子 |

**日课应用**：今日地支为你的桃花位 → 宜社交、约会、艺术创作。但须防酒色误事，特别是桃花逢合之日（今日地支既为桃花又与命局合），情欲更盛。

详见 [[桃花]]。

### 三、羊刃

**含义**：主刚烈、极端、血光。日课中见羊刃，主当日性情急躁、易冲动，防意外伤害。

**查法**：以日主天干取禄前一位。

| 日干 | 羊刃在 |
|:----:|:------:|
| 甲 | 卯 |
| 丙、戊 | 午 |
| 庚 | 酉 |
| 壬 | 子 |
| 乙 | 辰 |
| 丁、己 | 未 |
| 辛 | 戌 |
| 癸 | 丑 |

**日课应用**：今日地支为你的羊刃位 → 当日宜静不宜动，防冲动行事。若日课天干再透七杀（杀刃相见），则须格外谨慎，防血光之灾。但身弱者逢羊刃帮身，反有助力。

## 日课神煞的引动机制

### 一、冲合引动

神煞被引动的主要途径是**冲与合**：

- **冲**：今日地支冲命局中某柱地支，而该地支恰为某神煞所在 → 神煞被动，凶煞冲起则应凶，吉神冲散则失吉
- **合**：今日地支与命局中某柱地支合，而该地支恰为某神煞所在 → 神煞被合住，吉神合则力量增强，凶煞合则力量被牵制

> 战者，相克也；冲者，地支相冲也；和者，天干五合也；好者，同气相类也。
> —— [[滴天髓阐微]]（滴天髓阐微行13650-13664）

### 二、值临引动

今日地支恰好就是某神煞所在的地支位置 → 神煞当日当值，力量最为直接。

**示例**：日主甲木，贵人在丑未。今日地支为丑 → 天乙贵人当值，当日贵人运最旺。

### 三、暗拱引动

今日地支虽非神煞所在，但与神煞所在之地支形成三合、六合关系 → 神煞被暗拱，力量较弱但仍有影响。

**示例**：日主甲木，贵人在丑。今日地支为巳，巳酉丑三合金局 → 贵人被暗拱，当日亦有贵人暗助之象，但不如直临之强。

## 实战综合示例

### 示例：日主庚金身弱，用神为土金

今日为**乙丑**日，流年地支为**午**：

**一、十神判断**：
- 今日天干乙木 → 对庚金日主为正财（我克者）→ 身弱忌财耗身，不利

**二、十二长生判断**：
- 庚金养在丑 → 半吉，蓄养之气，尚可

**三、神煞判断**：
- 今日地支丑 → 庚贵人在丑 → **天乙贵人当值**，贵人运旺
- 流年午火 → 午为太岁 → 今日丑与太岁午无冲无合，平稳
- 桃花：庚日主日支若在巳酉丑三合之内 → 今日丑为桃花？须看日支具体为何

**四、综合断语**：
今日虽正财透出有耗身之虑，但庚金坐丑得养气之地，又得天乙贵人当值，主当日虽有财务或利益方面的事务需处理（正财），但有贵人暗助，结果不至于差。宜主动求人帮忙，忌独自硬扛。
