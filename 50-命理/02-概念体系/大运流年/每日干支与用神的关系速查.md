# 每日干支与用神的关系速查

> 属于 [[日课推算法]] | 相关：[[十神总论]]、[[十二长生]]、[[用神总论]]

## 用途

本表用于已知日主天干的情况下，快速判断**今日天干**所代表的十神性质、今日地支所处的十二长生状态，从而初步判断今日吉凶倾向。

使用步骤：
1. 确定你的日主天干（八字日柱天干）
2. 查万年历确定今日天干地支
3. 用表一查今日天干的十神性质
4. 用表二查今日地支的十二长生状态
5. 结合用神喜忌综合判断

## 综合判断速查流程

拿到今日干支后，按以下流程逐步判断：

```
今日干支 = (天干，地支)
    │
    ├── 查表一 → 今日天干 = X十神
    │       │
    │       ├── X 为用神所喜 → 有利 ✓
    │       └── X 为用神所忌 → 不利 ✗
    │
    ├── 查表二 → 今日地支 = Y长生状态
    │       │
    │       ├── Y 为吉位（长生/冠带/临官/帝旺）→ 得力 ✓
    │       ├── Y 为半吉（沐浴/胎/养）→ 中平 ◎
    │       └── Y 为凶位（衰/病/死/墓/绝）→ 失力 ✗
    │
    └── 综合十神 + 长生 → 初判今日吉凶倾向
            │
            ├── 天干有利 + 地支得力 → 大吉
            ├── 天干有利 + 地支失力 → 小吉（有暗阻）
            ├── 天干不利 + 地支得力 → 小凶（有暗助）
            └── 天干不利 + 地支失力 → 大凶
```

> **注意**：此为初步速判。精确推算还需结合今日干支与大运、流年、原局的战冲和好关系，以及神煞参考。详见 [[日课推算法]]。

## 十神喜忌速记

以下为"身旺喜克泄耗、身弱喜生扶"原则的速查：

### 身弱日主（喜生扶）

| 十神 | 喜忌 | 今日倾向 |
|------|:----:|----------|
| 正印、偏印 | **喜** | 贵人相助、学习思考 |
| 比肩、劫财 | **喜** | 同类助力、社交活跃 |
| 食神 | 中平 | 泄身但有情，小有消耗 |
| 伤官 | **忌** | 泄身无情，防口舌是非 |
| 正财、偏财 | **忌** | 耗身求财，辛苦得之 |
| 正官 | **忌** | 压力约束，防官讼 |
| 七杀 | **忌** | 猛烈克身，防灾祸 |

### 身旺日主（喜克泄耗）

| 十神 | 喜忌 | 今日倾向 |
|------|:----:|----------|
| 正印、偏印 | **忌** | 生身过旺，防优柔寡断 |
| 比肩、劫财 | **忌** | 比劫争财，防破耗 |
| 食神 | **喜** | 泄秀有情，利才艺表达 |
| 伤官 | **喜** | 泄秀有力，利创新突破 |
| 正财、偏财 | **喜** | 消耗旺气，利财运 |
| 正官 | **喜** | 约束日主，利事业 |
| 七杀 | 中平 | 制身有力但须有制化 |
