# 吉神·年干取

> 属于 [[神煞总论|神煞总论]] | 本篇收录以年干为基准查取的吉神共8种

以年干为基准取神煞，是神煞体系中最基础的查法之一。年干代表祖上根基、先天禀赋，故以此取煞多主先天之福泽。

---

## 一、天乙贵人

### 查法口诀

> 甲戊庚牛羊，乙己鼠猴乡，丙丁猪鸡位，壬癸兔蛇藏，六辛逢虎马，此是贵人方。

| 天干 | 贵人在地支 |
|------|------------|
| 甲、戊、庚 | 丑（阴贵）、未（阳贵） |
| 乙、己 | 子（阴贵）、申（阳贵） |
| 丙、丁 | 亥（阴贵）、酉（阳贵） |
| 壬、癸 | 卯（阴贵）、巳（阳贵） |
| 辛 | 寅（阴贵）、午（阳贵） |

### 释义

天乙贵人者，三命中最吉之神。所至之处，一切凶煞隐然而避。主贵人扶助、逢凶化吉、功名早达、官禄易进。

> 天乙贵人者，三命中最吉之神也。若人遇之则荣，功名早达，官禄易进。
> —— [[三命通会]]·论天乙贵人

### 喜忌

- 喜：坐旺地、得生有气、不落空亡、不被冲破
- 忌：落空亡、被刑冲破害、入死绝之地
- 阳贵（昼贵）生于昼间取之，阴贵（夜贵）生于夜间取之

### 关联

与正官同现主仕途通达，与食神同现主文艺成名，与羊刃七煞同现可化煞为权。详见 [[天乙贵人]]

## 二、太极贵人

### 查法口诀

> 甲乙子午全，丙丁鸡兔年，戊己四季位，庚辛寅亥间，壬癸巳申上，太极贵人言。

| 天干 | 太极在地支 |
|------|------------|
| 甲、乙 | 子、午 |
| 丙、丁 | 酉、卯 |
| 戊、己 | 辰、戌、丑、未 |
| 庚、辛 | 寅、亥 |
| 壬、癸 | 巳、申 |

### 释义

太极者，造化之本源。命带太极贵人者，主聪明好学，做事有始有终，喜研宗教哲学、阴阳术数。

> 太极贵人者，造化始终相保之谓也。
> —— [[三命通会]]·论太极贵人

### 喜忌

- 喜：与华盖同现，主学术大成；与正印同现，主学问渊博
- 忌：不宜落空亡，否则虽好学而无成

### 关联

与华盖性质相近，皆主好学深思。太极偏向哲理玄学，华盖偏向技艺艺术。

## 三、天厨贵人

### 查法口诀

> 甲食丙兮丙食戊，戊食庚兮庚食壬，壬食甲兮乙食丁，丁食己兮己食辛，辛食癸兮癸食乙，此是天厨贵人诀。

以年干之食神，若坐禄位（即食神之临官地支），即为天厨贵人。

| 年干 | 天厨在地支 |
|------|------------|
| 甲 | 巳（丙之禄） |
| 乙 | 午（丁之禄） |
| 丙 | 申（戊之禄） |
| 丁 | 酉（己之禄） |
| 戊 | 申（庚之禄） |
| 己 | 酉（辛之禄） |
| 庚 | 亥（壬之禄） |
| 辛 | 子（癸之禄） |
| 壬 | 寅（甲之禄） |
| 癸 | 卯（乙之禄） |

### 释义

天厨贵人主饮食丰足、衣禄无忧。食神逢禄，有如御厨供膳，一生不愁衣食。

> 天厨贵人者，食神逢禄之谓也。主人衣禄丰足，一生不愁饮食。
> —— [[三命通会]]·论天厨

### 喜忌

- 喜：与食神同现，福力倍增；与财星同现，财禄兼得
- 忌：不宜被冲破，否则衣食有损

### 关联

天厨贵人本质上是食神逢禄的特殊组合，与食神格相辅相成。

## 四、福星贵人

### 查法口诀

> 甲丙相邀入虎乡，乙逢子鼠己丁猪，庚辛蛇兔壬癸马，戊猴己犬最为良。

| 年干 | 福星在地支 |
|------|------------|
| 甲、丙 | 寅 |
| 乙 | 子 |
| 己、丁 | 亥 |
| 庚、辛 | 巳、卯 |
| 壬、癸 | 午 |
| 戊 | 申 |
| 己 | 戌 |

### 释义

福星贵人主一生福厚，逢凶化吉。命带福星者，纵遇灾厄亦能化解，一生多有福荫庇护。

> 福星贵人者，主一生福厚，逢凶化吉。
> —— [[渊海子平]]·论福星贵人

### 喜忌

- 喜：与天乙贵人同现，福力最厚；与正官正印同现，富贵双全
- 忌：不宜落空亡、被冲破

### 关联

福星贵人与天乙贵人皆为吉神，但天乙侧重贵人扶助，福星侧重自身福泽。

## 五、文昌贵人

### 查法口诀

> 甲乙巳午报君知，丙戊申宫丁己鸡，庚猪辛鼠壬逢虎，癸人见兔入云梯。

| 年干 | 文昌在地支 |
|------|------------|
| 甲 | 巳 |
| 乙 | 午 |
| 丙、戊 | 申 |
| 丁、己 | 酉 |
| 庚 | 亥 |
| 辛 | 子 |
| 壬 | 寅 |
| 癸 | 卯 |

### 释义

文昌贵人主学业功名、聪明好学。命带文昌者，读书考试多有利，文章出众，利于科举功名。

> 文昌贵人者，主聪明好学，文章出众，利于科举功名。
> —— [[三命通会]]·论文昌

### 喜忌

- 喜：与正印、学堂同现，学业大成；与官星同现，功名显达
- 忌：不宜被冲破、落空亡，否则虚有文名

### 关联

文昌贵人与学堂、词馆性质相近，皆主学业。文昌偏重天赋聪颖，学堂偏重好学不倦，词馆偏重文章显达。

## 六、金舆

### 查法

以年干之禄神，取禄前二辰即为金舆。

| 年干 | 禄在 | 金舆在 |
|------|------|--------|
| 甲 | 寅 | 辰 |
| 乙 | 卯 | 巳 |
| 丙、戊 | 巳 | 未 |
| 丁、己 | 午 | 申 |
| 庚 | 申 | 戌 |
| 辛 | 酉 | 亥 |
| 壬 | 亥 | 丑 |
| 癸 | 子 | 寅 |

### 释义

金舆者，如君子之车舆，主富贵荣华。命带金舆者，一生多得享用，妻贤子孝，出行有车马之便。

> 金舆者，禄前二辰，如人之乘车舆也。主富贵，妻贤子孝。
> —— [[三命通会]]·论金舆

### 喜忌

- 喜：与禄神同现，富贵兼得；与财星同现，一生享用不尽
- 忌：不宜被冲破，否则虚有其表

### 关联

金舆与禄神密切相关，禄神主官禄俸禄，金舆主享用富贵。二者同现，福力最厚。

## 七、红艳煞

### 查法口诀

> 甲逢午兮乙逢申，丙寅丁未戊辰真，己辰庚戌辛逢酉，壬子癸申是红艳。

| 年干 | 红艳在地支 |
|------|------------|
| 甲 | 午 |
| 乙 | 申 |
| 丙 | 寅 |
| 丁 | 未 |
| 戊 | 辰 |
| 己 | 辰 |
| 庚 | 戌 |
| 辛 | 酉 |
| 壬 | 子 |
| 癸 | 申 |

### 释义

红艳煞主情欲风流。**女命最忌**，命带红艳者多主情感复杂、风流韵事。男命逢之则主人缘好、有魅力。

> 红艳煞者，女命最忌，主情欲风流。男命逢之，主人缘好，有魅力。
> —— [[渊海子平]]·论红艳煞

### 喜忌

- 喜（男命）：与桃花同现，人缘极佳
- 忌（女命）：与桃花同现，感情风波不断；不宜再见伤官、七煞

### 关联

红艳煞与桃花性质相近，皆主人缘情感。但红艳偏重情欲，桃花偏重才艺人缘。女命逢红艳，须格外留意婚姻感情。

## 八、禄神

### 查法口诀

> 甲禄在寅乙禄卯，丙戊禄在巳，丁己禄在午，庚禄在申辛禄酉，壬禄在亥癸禄子。

| 年干 | 禄在地支 |
|------|----------|
| 甲 | 寅 |
| 乙 | 卯 |
| 丙、戊 | 巳 |
| 丁、己 | 午 |
| 庚 | 申 |
| 辛 | 酉 |
| 壬 | 亥 |
| 癸 | 子 |

### 释义

禄神者，官禄之谓也。命带禄神者，主官职俸禄、衣食丰足。禄神为养命之源，最喜坐旺地、不被冲破。

> 禄者，爵禄也。命中得之，主官职俸禄，衣食丰足。
> —— [[三命通会]]·论禄

### 喜忌

- 喜：坐旺地、与财官同现、不落空亡
- 忌：被冲破（谓之破禄）、落空亡、入死绝之地
- 禄神在日支最佳，谓之"坐禄"，主自立成家

### 关联

禄神与建禄格、归禄格、拱禄格等格局密切相关。禄神为日干临官之位，是十二长生中的关键节点。详见 [[神煞总论|神煞总论]]中D类日干取煞。

## 小结

以年干取煞的8种神煞，吉凶分明：

| 性质 | 神煞 | 核心象征 |
|------|------|----------|
| 上吉 | 天乙贵人 | 贵人扶助 |
| 吉 | 太极贵人 | 聪明有终 |
| 吉 | 天厨贵人 | 衣食丰足 |
| 吉 | 福星贵人 | 一生福厚 |
| 吉 | 文昌贵人 | 学业功名 |
| 吉 | 金舆 | 富贵享用 |
| 中性偏凶 | 红艳煞 | 情欲风流 |
| 吉 | 禄神 | 官禄俸禄 |

此8种神煞中，天乙贵人与禄神最为紧要，为论命时必查之项。其余6种可作为辅助参考，在格局分析的基础上增添细节。

## 每种神煞的入命表现详解

### 天乙贵人入命之性情

《烛神经》详论天乙贵人入命之性情特征：贵人遇生旺，则形貌轩昂、性灵颖悟、理义分明、不喜杂术、纯粹大器、身蕴道德、众人钦爱。贵人遇死绝，则执拗自是、喜游近贵。贵人与劫煞并，则貌厚有威、多谋足计。贵人与官符并，则文翰飘逸、高谈雄辩。贵人与建禄并，则文翰纯实、济惠广游、君子人也。贵人落天中（空亡），则有伶伦之态、好呕吟、伎艺人也。

### 太极贵人入命之表现

太极贵人入命者，主聪明好学、做事有始有终。其性情偏向哲理思辨，喜研宗教哲学、阴阳术数、天文地理。与华盖性质相近，但太极偏向哲理玄学，华盖偏向技艺艺术。太极贵人入命者，做事有始有终，不轻言放弃，有探索精神。

### 天厨贵人入命之表现

天厨贵人入命者，主一生不愁衣食。食神逢禄，有如御厨供膳。此神煞入命者，多与饮食行业有缘，或从事餐饮、食品、农业等相关领域。天厨贵人亦主生活品味高，注重饮食质量，有口福之享。

### 福星贵人入命之表现

福星贵人入命者，主一生福厚，纵遇灾厄亦能化解。与天乙贵人之别在于：天乙侧重贵人扶助（外力），福星侧重自身福泽（内力）。福星入命者，性格乐观豁达，遇事不慌，常有"歪打正着"之好运。

### 文昌贵人入命之表现

文昌贵人入命者，主聪明好学、文章出众。此神煞最利考试、升学、功名。文昌入命者，记忆力强、理解力佳，善于文字表达。与学堂词馆同见，学业大成；与正印同见，学问渊博；与官星同见，功名显达。

### 金舆入命之表现

金舆入命者，主富贵享用。如君子之车舆，一生多得享用。金舆入命者，多有车马之便，生活条件优越。与禄神同见，富贵兼得；与财星同见，享用不尽。金舆亦主配偶贤能，妻贤子孝。

### 红艳煞入命之表现

红艳煞入命者，男命主人缘好、有魅力，异性缘旺；女命主情感复杂、风流韵事。红艳煞与桃花性质相近，但红艳偏重情欲，桃花偏重才艺人缘。女命逢红艳，须格外留意婚姻感情，不宜再见伤官七煞。

### 禄神入命之表现

禄神入命者，主官职俸禄、衣食丰足。禄神为养命之源，最喜坐旺地、不被冲破。禄神在日支最佳，谓之"坐禄"，主自立成家。禄神被冲谓之"破禄"，主官运不顺、衣食有损。禄神落空亡，主有名无实。

## 各神煞之间的配合关系

八种年干吉神之间存在多种配合关系：

- **天乙贵人 + 禄神**：贵禄双全，主富贵兼得。贵人扶助而有禄可享，此为最佳配合。
- **天乙贵人 + 文昌贵人**：主学业仕途两全。贵人引荐而文昌助学业，主功名早达。
- **太极贵人 + 华盖**：主学术大成。太极主哲理，华盖主技艺，二者同见，主学问渊博、技艺精湛。
- **文昌贵人 + 学堂词馆**：主文章显达。文昌主聪颖，学堂主好学，词馆主文章，三者同见，主文名远播。
- **禄神 + 金舆**：主富贵享用。禄主官禄，金舆主享用，二者同见，主一生荣华。
- **福星贵人 + 天乙贵人**：福力最厚。福星主自身福泽，天乙主外力扶助，内外兼修，主一生逢凶化吉。

## 神煞在不同柱的力量差异

同一神煞在不同柱位，力量有明显差异。《三命通会》论贵人云："时为上贵，日为中贵，月为常庶。"此论可推广至多数神煞：

- **时柱**：力量最强。时柱为归宿，神煞在此，主晚年应验最明显，且力量持久。
- **日柱**：力量次之。日柱为命主自身，神煞在此，主自身特质明显。
- **月柱**：力量又次之。月柱为事业宫，神煞在此，主青年至中年应验。
- **年柱**：力量较弱。年柱为祖业根基，神煞在此，主先天禀赋，但需其他柱配合方能彰显。

然天乙贵人在年柱亦不可忽视，因年柱代表先天福泽，贵人在年主出身好、幼年得庇护。各神煞之力量差异，须结合具体神煞特性综合判断。
