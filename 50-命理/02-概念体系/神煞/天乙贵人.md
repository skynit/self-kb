# 天乙贵人

> 详细分类参见 [[吉神_年干取|吉神·年干取]] | 回到 [[神煞总论|神煞总论]]

## 定义

天乙贵人，命理十二神煞之首，所至之处一切凶煞隐然而避。

> 天乙者，乃天上之神，在紫微垣、阊阖门外，与太乙并列，事天皇大帝，下游三辰……其神最尊贵，所至之处，一切凶煞隐然而避。
> —— [[三命通会]]·论天乙贵人

## 查法

以年干或日干查四柱地支：

| 年/日干 | 贵人在 |
|:-------:|:------:|
| 甲戊庚 | 丑、未 |
| 乙己 | 子、申 |
| 丙丁 | 亥、酉 |
| 壬癸 | 卯、巳 |
| 辛 | 寅、午 |

**口诀**：甲戊庚牛羊，乙己鼠猴乡，丙丁猪鸡位，壬癸兔蛇藏，辛逢虎马乡。

## 详解

- **位置**：贵人在年月为"外贵人"，主父母荫庇、社会人脉；在日时为"内贵人"，主自身能力、配偶子女之助
- **昼夜贵人**：丑未为夜贵，子申为昼贵。昼生人喜见昼贵，夜生人喜见夜贵
- **入庙**：贵人坐旺地（如甲贵人在丑未，丑未为土旺之地），力量最强
- **逢冲逢合**：贵人忌被冲散，逢合则贵人与我有情

## 昼夜贵人详解

天乙贵人分昼夜二贵，此为用贵人之要诀。《壶中子》云："贵人分治昼夜，各自专权，以昼生遇昼贵，夜生遇夜贵，为得力。"《三命通会》详论其分法：以寅申分阴阳，冬至后用阳贵，夏至后用阴贵。人命一阳生后遇阳贵为得力，一阴生后遇阴贵为得力。

具体而言，阳贵（昼贵）取法为：甲在未、乙在申、丙在酉、丁在亥、戊在丑、己在子、庚在丑、辛在寅、壬在卯、癸在巳。阴贵（夜贵）取法为：甲在丑、乙在子、丙在亥、丁在酉、戊在未、己在申、庚在未、辛在午、壬在巳、癸在卯。

昼夜贵人之分，本质上是五行阴阳消长之理。阳贵取天干之阳气所聚，阴贵取天干之阴气所藏。昼生人阳气盛，故喜阳贵扶助；夜生人阴气重，故喜阴贵荫庇。若昼夜颠倒，则贵人之力减半。

### 贵人在不同柱的含义

贵人所在之柱不同，所主之事亦异：

- **年柱贵人**：主祖上荫庇、先天福泽。年柱为祖业根基，贵人在年，主出身书香门第或官宦之家，幼年得长辈庇护。
- **月柱贵人**：主父母扶助、社会人脉。月柱为父母宫兼兄弟宫，贵人在月，主父母有助力，兄弟朋友多有贵人。
- **日柱贵人**：主配偶贤能、自身能力。日支为夫妻宫，贵人在日，主配偶出身好或有能力，自身亦得贵人之助。
- **时柱贵人**：主子女孝顺、晚年享福。时柱为子女宫兼晚年归宿，贵人在时，主子女有出息，晚年多得儿孙之福。

《三命通会》又云："时为上贵，日为中贵，月为常庶。"此言贵人在时柱力量最强，日柱次之，月柱又次之。盖时柱为归宿，贵人在此，主一生晚年最得力。

### 贵人入命的性情表现

《烛神经》详论贵人入命之性情特征："天乙贵遇生旺，则形貌轩昂性灵颖悟，理义分明，不喜杂术，纯粹大器，身蕴道德，众人钦爱。死绝则执拗自是，喜游近贵。与劫煞并，则貌厚有威，多谋足计。与官符并，则文翰飘逸，高谈雄辩。与建禄并，则文翰纯实，济惠广游，君子人也。"

此段精辟描述了贵人入命者的基本气质：形貌端正、气质不凡、聪明有悟性、品德高尚、受人尊敬。但若贵人落空亡或死绝，则气质大减，变为执拗自是、攀附权贵之辈。

### 贵人逢冲逢合的吉凶

贵人最喜生旺无冲破。《理愚歌》云："贵人或落空亡里，禄马背违如不值。"《宝鉴》云："贵人无气，虽有如无。"《洞玄经》云："贵人嗔则凶来。"此三句道出贵人之忌：

- **贵人逢冲**：冲则散，贵人被冲散则无力扶助。如甲贵人在丑未，若命局或流年有未冲丑、丑冲未，则贵人之力大减。
- **贵人逢合**：合则绊，贵人被合则与我有情但被牵绊。贵人逢合，主贵人虽有但来迟，或贵人自身有牵累。
- **贵人落空亡**：空亡主虚，贵人落空亡则有名无实，虽有贵人之名而无贵人之实。
- **贵人入死绝**：贵人入死绝之地则无力，"虽有如无"，不可作吉论。

### 贵人与其他神煞的配合

贵人与其他神煞配合，吉凶各异：

- **贵人 + 天德月德**：吉力最强。《三命通会》云："贵神在位，诸煞伏藏；二德扶持，众凶解散。"三者同见，逢凶化吉之力倍增。
- **贵人 + 三奇**：主超凡之才。三奇贵人与天乙贵人同见，主人精神异常、勋业超群。
- **贵人 + 华盖**：主聪明脱俗。华盖主孤高才华，贵人主扶助，二者同见，主人聪慧而有贵人赏识。
- **贵人 + 驿马**：主变动中有贵人相助。出行迁动之时得贵人扶助，事业变动顺利。
- **贵人 + 羊刃七煞**：可化煞为权。贵人制羊刃之凶性，七煞与羊刃配合，反主武贵。
- **贵人 + 劫煞亡神**：贵人可制劫煞亡神之凶，减轻灾咎。但若贵人本身无力（落空亡、死绝），则制煞之力不足。

## 象征

- 一生多遇贵人相助
- 逢凶化吉，遇难呈祥
- 社交能力强，人缘好
- 容易得到长辈、上级的提携
