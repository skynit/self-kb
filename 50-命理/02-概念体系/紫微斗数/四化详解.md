# 四化详解

> 属于 [[紫微体系MOC]] | 相关：[[十四主星]]、[[紫微斗数总论]]

## 定义

四化是紫微斗数推演吉凶的核心机制——**化科、化权、化禄、化忌**四颗化曜，依天干而飞布各宫，赋予星曜吉凶变化。四化无需计算飞星，以本命盘四化为主。

> 科权禄忌四化为主，无需计算飞星。
> —— [[天纪-紫微斗数-笔记]]

---

## 化科

**含义**：科名、声名远播。

**核心特质**：
- 金榜题名
- 文笔优秀
- 才艺超群
- 为人师表
- 专业技术专长

**在不同宫位**：

| 宫位 | 含义 |
|------|------|
| 命宫 | 读书考试都很好，有专长 |
| 官禄宫 | 去考公家单位，适合教师 |
| 财帛宫 | 有技术专长，自由职业 |
| 夫妻宫 | 配偶有专科技术专长 |

> 化科星性：a.主科名（金榜题名，文笔优秀，才艺超群，为人师表）；b.声名远播。
> —— [[天纪-紫微斗数-笔记]]

**面相**：手上天柱纹（事业线）主科。天柱纹明显，科甲旺。眉毛短小，有科无权，师爷像。

---

## 化权

**含义**：官印、性情刚直。

**核心特质**：
- 领导之才
- 掌权主事
- 个性强、有主见

**在不同宫位**：

| 宫位 | 含义 |
|------|------|
| 命宫 | 先天是领导之才，个性强有主见 |
| 夫妻宫 | 配偶性刚，主见很强 |
| 财帛宫 | 自己做生意做老板，掌权 |
| 官禄宫 | 最好，代表有官有权 |
| 朋友宫 | 与朋友合伙，朋友掌权 |

> 化权星性：a.官印；b.性情刚直。命宫化权，先天是领导之才。夫妻宫化权，配偶性刚，主见很强。
> —— [[天纪-紫微斗数-笔记]]

**面相**：颧大有肉主权。眉骨（犀牛骨）突出主有权。

**特殊规则**：命中有科无权，代表有技术专长，适合佐才、参谋、顾问。

---

## 化禄

**含义**：钱财、财禄。

**核心特质**：
- 财源广进
- 悭吝（守财奴倾向）
- 适合从商

**在不同宫位**：

| 宫位 | 含义 |
|------|------|
| 命宫 | 天生祖业丰厚 |
| 父母宫 | 父母从商，很会做生意赚钱 |
| 财帛宫 | 自己会做生意 |
| 官禄宫 | 贪官或手握财权 |
| 朋友宫 | 合伙生意大利，自己很会做人 |

> 化禄星性：a.钱财；b.悭吝（守财奴）。
> —— [[天纪-紫微斗数-笔记]]

**面相**：鼻孔小代表悭吝（守财奴）。鼻子很大颧骨很高掌握财权。

## 化忌

**含义**：劫杀、想不开。

**核心特质**：
- 官司、横祸、意外
- 自身想不开
- 停滞、孤独、破耗

**在不同宫位**：

| 宫位 | 含义 |
|------|------|
| 命宫 | 早年不顺，心胸不开 |
| 迁移宫（冲命） | 大凶，半空折翅格 |
| 夫妻宫 | 婚姻有灾，主生离 |
| 子女宫 | 无子或有子冲突大 |
| 父母宫 | 与父母相克 |
| 财帛宫 | 诸事不顺 |
| 兄弟宫 | 兄弟不和或夭折 |
| 朋友宫 | 合伙必败，朋友变仇人 |

> 化忌星性：a.劫杀（官司、横祸、意外等等）；b.自身想不开。
> —— [[天纪-紫微斗数-笔记]]

**化解之道**：化解灾厄在"戒慎"——做事开始要知戒（戒之初），好运高峰要知戒（戒之盛）。

## 四化组合

### 科权相逢

科权同宫或会照，主为行业领导。如医院主任、院长、学校校长、法官。

### 权禄相逢

权禄同宫，代表自己做事业当老板。在财帛宫尤佳。

### 科权禄三会

命宫三方四正科、权、禄三会，代表一方之主。若科在官禄、禄在财帛、权在对面或官禄，为天子命。

### 科忌同宫

化科化忌在一起，屠夫命。

### 禄忌同宫

禄和忌同宫，不可朝此方向（如书桌、睡床方位）。

## 化忌冲命与半空折翅

化忌在迁移宫对冲命宫，三方四正无吉星，称为**半空折翅格**，大限在中年（30岁左右），主中年横夭。

> 半空折翅格：化忌冲命，三方四正无吉星，半空折翅格，大限在30岁左右。
> —— [[天纪-紫微斗数-笔记]]

**化解方法**：
- 二姓一生（过继给别人养能化解）
- 未婚男子睡东宫，脚朝延年方（命盘中有解厄制化的星的方向）

## 四化的飞化原理

四化的飞布，是紫微斗数推演吉凶的核心机制。四化依天干而飞布各宫，赋予星曜吉凶变化。

### 本命四化

本命四化由出生年干决定。十天干各有固定的四化飞布：

| 年干 | 化科 | 化权 | 化禄 | 化忌 |
|------|------|------|------|------|
| 甲 | 天同 | 破军 | 廉贞 | 太阳 |
| 乙 | 天机 | 天梁 | 太阴 | 太岁 |
| 丙 | 文昌 | 天机 | 天同 | 廉贞 |
| 丁 | 天机 | 天同 | 太阴 | 巨门 |
| 戊 | 右弼 | 太阴 | 贪狼 | 天机 |
| 己 | 天梁 | 贪狼 | 武曲 | 文曲 |
| 庚 | 天同 | 武曲 | 太阳 | 太阴 |
| 辛 | 文曲 | 太阳 | 巨门 | 文昌 |
| 壬 | 左辅 | 天梁 | 武曲 | 紫微 |
| 癸 | 太阴 | 破军 | 巨门 | 贪狼 |

### 飞化的实质

四化的飞化，本质上是天干对星曜的"赋权"。当年干确定后，四颗化曜分别落在不同宫位，被化曜的星曜因此获得特殊的力量——化科增其科名之力，化权增其权势之力，化禄增其财禄之力，化忌增其劫杀之力。

> 科权禄忌四化为主，无需计算飞星。
> —— [[天纪-紫微斗数-笔记]]

倪海厦先生强调以本命盘四化为主，不需计算飞星。此为简明实用之法，适合初学者入门。

## 四化组合的各种情况

四化之间的组合，产生不同的化学反应，吉凶各异。

### 科权相逢

科权同宫或会照，主为行业领导。如医院主任、院长、学校校长、法官。此为最佳的四化组合之一——有名（科）有权（权），名利双收。

### 权禄相逢

权禄同宫，代表自己做事业当老板。在财帛宫尤佳——既有赚钱的能力（禄），又有掌权的本事（权），自立门户大吉。

### 科权禄三会

命宫三方四正科、权、禄三会，代表一方之主。若科在官禄、禄在财帛、权在对面或官禄，为天子命——有名、有权、有财，三全其美。

### 科忌同宫

化科化忌在一起，屠夫命。科主技术专长，忌主劫杀是非，二者同宫，以技术为业但行业带有凶险性质。

### 禄忌同宫

禄和忌同宫，不可朝此方向（如书桌、睡床方位）。禄主财，忌主劫，同宫则财中有劫，表面赚钱实则破耗。

### 权忌同宫

权主刚强，忌主是非。权忌同宫，个性刚强但容易惹是非，做官者须防官讼。

## 四化与大运流年的关系

四化不仅存在于本命盘中，也随大运流年而变化。

### 大运四化

每步大运（十年）有自己的四化飞布，由大运天干决定。大运四化叠加在本命四化之上，产生更复杂的吉凶变化。

**实例**：本命化禄在财帛宫（自己会做生意），大运化忌飞入财帛宫（诸事不顺），则这十年虽有赚钱之能，但运势不佳，事倍功半。

### 流年四化

每年流年也有自己的四化飞布，由流年天干决定。流年四化叠加在本命与大运四化之上，决定当年的具体吉凶。

**实例**：本命化科在官禄宫（适合考试），流年化科也飞入官禄宫（双科叠加），则此年考试大利，金榜题名。

### 四化叠加的层次

```
本命四化（一生之基调）
  + 大运四化（十年之趋势）
    + 流年四化（一年之变化）
      = 实际吉凶
```

三层四化的叠加，是紫微斗数推演吉凶的核心方法。本命四化定基调，大运四化定趋势，流年四化定应期。

### 四化与化解之道

化忌所在宫位是全盘最需注意的地方。化解之道在于"戒慎"——做事开始要知戒（戒之初），好运高峰要知戒（戒之盛）。同时可通过阳宅方位调整来减轻化忌的凶力。
