# 五行体系 MOC

> 五行是命理学的哲学根基，一切推演皆以五行为基础。
> "五行播于四时，是谓神功，乃三才之统系，万物之本原。"—— [[滴天髓阐微]]·天道章

## 关键关系

```
相生：木 → 火 → 土 → 金 → 水 → 木（生生不绝）
相克：木 → 土 → 水 → 火 → 金 → 木（制化之义）
```

### 生克辩证（出自 [[渊海子平]]·论五行生克制化）

| 原则 | 示例 |
|------|------|
| 旺则需克 | 金旺得火，方成器皿 |
| 生之太过反害 | 金赖土生，**土多金埋** |
| 克之反制 | 金能克木，**木坚金缺** |
| 以泄制强 | 强金得水，方挫其锋 |

## 五行旺衰

> 将来者进，是谓**相**；进而当令，是谓**旺**；功成者退，是谓**休**；退而无气，是谓**囚**。
> —— [[滴天髓阐微]]·理气章

- 详见 [[五行总论#五行旺衰：旺相休囚死|五行旺相休囚死]]
- **重要**：相妙于旺（上升期更有后劲），休甚于囚（开始衰退比触底更难受）

## 五行颠倒之理

> 木太旺者而似金，喜火之炼也；木旺极者而似火，喜水之克也。
> —— [[滴天髓阐微]]·衰旺章

详见 [[五行总论#五行颠倒之理|五行颠倒]]
