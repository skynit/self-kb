# 命理学知识库 — 目录规范与文档体系

> [!note] 当前位置
> 命理知识域已于 2026-07-16 迁入 `50-命理/`。本文继续规范命理域内部结构；全库顶层分类以 [[00-知识库/01-规范/知识库分类规范|知识库分类规范]] 为准。

## 一、设计哲学

本知识库遵循 **Zettelkaten（卡片笔记）+ PARA（领域分区）** 的混合方法论：

- **经典原文**保持原貌，作为不可篡改的"源数据层"
- **概念体系**按知识域拆分，每个概念一个原子笔记
- **技法体系**面向实战应用，可快速检索
- **学习笔记**记录个人理解，随时间迭代
- **卡片库**承载碎片化的洞察和关联

## 五、链接策略

### 5.1 双向链接原则

每个笔记**至少包含 3 个双向链接**：

1. **向上链接** → 所属 MOC
2. **平级链接** → 相关概念
3. **向下链接** → 派生概念或实例

示例（`天干相合.md`）：

```markdown
> 属于 [[50-命理/00-Meta/干支体系MOC]] | 相关：[[天干相克]]、[[地支六合]]

## 出处
- [[渊海子平/天干相合]] 原文
- [[三命通会/卷一]] 相关论述

## 延伸
- [[50-命理/02-概念体系/干支/天干相合|与天干相克的对比]]
```

### 5.2 嵌入（Embed）策略

对于关键原文段落，使用嵌入引用而非复制：

```markdown
## 原文摘录
![[渊海子平#论五行所生之始]]
```

## 六、写作流程

### 新增一条知识的步骤

```
1. 确定知识类型 → 概念？技法？实例？卡片？
2. 选择对应模板 → templates/ 目录
3. 创建笔记 → 放入对应目录
4. 填写 Frontmatter
5. 建立链接 → 至少 3 个双向链接
6. 更新所属 MOC
7. 回顾：是否有其他笔记需要关联到此新笔记？
```

### 每周回顾检查

```
- [ ] 新增笔记是否都有 Frontmatter？
- [ ] 新增笔记是否都建立了双向链接？
- [ ] MOC 是否需要更新？
- [ ] 卡片库中是否有可以合并的概念？
```
